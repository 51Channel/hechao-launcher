## 变更内容

1. 服务器、活动、下载、账户和设置五个工作区统一为紧凑工作台布局，白天和黑夜主题可在
   运行时切换并持久化；
2. 服务器目录改为更适合反复浏览和启动的双列列表与 Inspector 结构，最小窗口自动回落
   单列；
3. 增加设置兼容迁移与 Debug UI 预览入口，保留既有登录、下载、Java、游戏启动和更新
   业务命令；

5. 官方组合标改用高分辨率深浅主题资源，运行时主题切换与对应冷启动截图逐字节一致；
6. 增加 XAML 合同测试，防止后续再次用普通图标加文字替代组合标，或把玩家头像固定成
   启动器图标。

本版继续沿用最终赫朝品牌图标、DPAPI 持久登录和启动器自动更新。安装包与主程序仍按项目
决策保持 `NotSigned`，完整性由 HTTPS、私有 OSS、认证更新端点、长度和 SHA-256 共同保证。

若更新分发出现问题，恢复上述环境备份并只重启 `hechao-launcher-api.service`，即可让尚未
升级的客户端重新获取 `0.15.14` 元数据。已经安装 `0.15.15` 的客户端不会自动降级，程序
修复应发布更高版本。不得覆盖 `0.15.15` 的不可变 OSS 对象或标签，也不得为启动器回滚
操作游戏服。
