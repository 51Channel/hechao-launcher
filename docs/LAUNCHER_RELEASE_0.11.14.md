## 变化

- “启动时检查客户端更新”开关现在会真实控制首次客户端状态扫描，不再只是保存设置。
- 关闭开关后，首次目录加载显示“启动检查已关闭”，主按钮显示“检查客户端”，不在
  后台读取本地档案状态。
- 玩家第一次进入服务器前仍会强制检查客户端，不能利用该开关绕过版本、完整性或
  Java 准备流程。
- 重新打开开关时立即补做当前档案检查；安装、修复和回滚成功后会更新已检查状态。
- 本地检查失败时保留启动器进程，状态回到“客户端检查未完成”，允许玩家重试。
- 两套响应式设置布局统一使用同一文案和行为说明。
