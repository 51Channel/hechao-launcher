## 本轮改版

玩家市场上架页改为明确的功能模块布局：

- 顶部只承载页面标题和返回操作，正文从稳定起点开始；
- 左侧“物品槽”独立承载可交互上架槽和物品摘要；
- 右侧“定价与操作”独立承载价格输入框和确认上架按钮；
- 左下“玩家背包”独立框住原生背包槽位，继续保留拖放和 Shift 点击；
- 右下“上架说明”独立显示服务端状态、最低价格、手续费和操作顺序；
- 移除跨区域长文案，避免状态、价格和背包槽位互相覆盖。
