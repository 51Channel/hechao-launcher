## 发布范围

1. “活动”页由活动服卡片目录改为周一开头、固定六周的月历。
2. 月历使用启动器服务器目录中的活动排期；官网日程使用同一 Launcher API 的匿名脱敏投影，后台活动排期仍是唯一写入来源。
3. 支持前后月份、回到今天、选择日期、跨日活动、待排期活动和所选日期详情。
4. 活动客户端下载、更新和下载后加入服务器主页的原有闭环保留。
5. 官网或后台当前没有活动时仍显示完整月历，只在月历上方展示同步状态，不回退为整页空状态。

## 发布边界

- 不改变活动目录、客户端档案、服务器开放状态或官网内容。
- 不启动、停止或重启 Minecraft、Velocity、服控代理或 Publisher Agent。
- 生产切换只允许更新启动器私有 OSS 对象与 Launcher API 更新元数据；切换前备份 API 环境文件，失败自动恢复。
- 最低支持版本保持 `0.12.3`，不扩大强制更新边界。

## 回滚

发布失败时保持 `LatestVersion=0.14.2`。切换后若发现分发异常，恢复切换前 API 环境备份或关闭 `LauncherUpdates__Enabled`，再只重启 Launcher API。已经安装 `0.15.0` 的客户端不自动降级；代码回退必须基于 `0.14.2` 发布更高版本。
