# 启动器 0.11.9 小范围测试手册

> 范围：2 至 3 名内部玩家
>
> 目标：确认 `0.11.8` 的 Fabric 主类加载阻断已修复

## 安装前

- 停止使用 `0.11.8`，只使用管理员提供的 `0.11.9` 私有短时链接。
- 文件名必须为 `Hechao-Launcher-Setup-0.11.9-win-x64.exe`。
- 文件大小必须为 `61,815,081` 字节。
- SHA-256 必须为
  `C80782CD522EFBCC1E0834AEE46583E8C0355B8B787B7174CAAF5C808CA19469`。
- 可以直接覆盖 `0.11.8`，不要删除客户端、Java 或游戏数据目录。

## 必测流程

1. 覆盖安装后确认版本显示 `0.11.9`，账号、Minecraft 绑定、内存和档案仍保留。
2. 使用之前会立即异常退出的同一数据目录和基础客户端点击“进入服务器”。
3. 确认进程不再在一秒内退出，也不再出现“Minecraft 异常退出”提示。
4. 确认 Minecraft 窗口出现并进入大厅；退出后查看最新日志没有
   `KnotClient` 或 `ClassNotFoundException`。
5. 选择 PVP 1.20.1 档案，确认仍显示 Java 17；基础档案继续显示 Java 21。
6. 分别测试自动 Java和一个兼容的自定义 Java，确认两者都能进入初始化。
7. 关闭并重新打开启动器，再次进入同一服务器，确认安全别名可重复复用。

## 回报内容

提供启动器版本、档案 ID、发生时间、是否使用自动 Java和玩家主动生成的脱敏诊断包。
不要发送 Microsoft 密码、浏览器地址栏、令牌、赫朝会话、私有下载链接或 Java
完整个人路径。

## 通过条件

- 原问题目录可以正常加载 Fabric 主类并启动 Minecraft。
- 自动 Java、自定义 Java和不同档案主版本保持独立。
- 覆盖升级不清除账号、设置、客户端、存档或下载缓存。
- 启动失败时启动器保持运行并提供可诊断错误。
