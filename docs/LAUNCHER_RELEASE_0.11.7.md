## 修复范围

`0.11.6` 在进入服务器时只尝试使用内存或 MSAL 缓存中的 Minecraft 游戏会话。
缓存不存在或 Microsoft 要求重新交互时，界面错误提示玩家退出赫朝账号后重新登录。
赫朝账号登录不会执行 Microsoft OAuth，而且退出赫朝账号还会清理 Microsoft 缓存，
因此重复操作不能恢复游戏凭据。

`0.11.7` 将社区身份与游戏凭据刷新重新接通：

- 进入服务器时仍先静默续期，避免正常玩家重复打开浏览器。
- 静默续期不可用时自动显示现有 Microsoft 等待层并打开系统浏览器。
- 浏览器认证成功后继续原来的启动和 Velocity 一次性授权，不要求再次点击。
- 交互认证得到的 Minecraft UUID 必须与赫朝账号已绑定 UUID 一致。
- 选错 Microsoft 账号、取消认证、配置缺失和登录失败都有独立提示，不会改绑身份、
  启动 Minecraft 或退出启动器。
- 删除“退出赫朝账号后重新登录”的错误恢复建议。

## 验收证据
