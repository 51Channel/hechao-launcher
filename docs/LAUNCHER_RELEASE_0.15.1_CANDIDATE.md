3. Java、内存和游戏目录进入首屏快捷设置；客户端安装、更新、修复、回滚、删除和
   自定义 Java 等完整能力继续保留。

5. 活动月历、客户端下载、自更新、服务器目录过滤和游戏启动状态机均不改变。

## 发布边界

- 不改变活动目录、客户端档案、服务器开放状态、官网内容或后台数据。
- 不启动、停止或重启 Minecraft、Velocity、服控代理或常驻 Publisher Agent。
- 生产切换只更新新的私有 OSS 安装包和 Launcher API 更新元数据；切换前备份 API
  环境文件，失败时自动恢复。
- 最低支持版本保持 `0.12.3`，不扩大强制更新边界。

## 回滚

发布失败时保持 `LatestVersion=0.15.0`。切换后如发现分发异常，恢复 API 环境备份或
关闭 `LauncherUpdates__Enabled`，再只重启 Launcher API。已经安装 `0.15.1` 的客户端
不会自动降级；代码修复继续使用更高版本，禁止覆盖任何已上传对象。
