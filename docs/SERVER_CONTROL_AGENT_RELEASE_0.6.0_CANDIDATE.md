# ServerControlAgent 0.6.0 动态部署槽候选

> 日期：2026-08-15
>
> 目标：仅升级 owl5；owl9 保持 `0.4.0`。
>
> 状态：候选已验证，尚未发布生产。

## 变更

- 新增结构化 `CreateDeploymentSlot` 命令，只从固定 `activity` 模板派生动态槽。
- 每个动态槽使用独立 `E:\HechaoActivitySlots\<serverId>` 目录、主机固定文件快照和
  `Hechao-Server-<serverId>` 无触发器计划任务。
- 动态槽原子保存到代理状态目录的 `dynamic-deployment-slots.json`，代理重启后重新
  验证并载入。
- 创建失败或取消会清理本轮目录、计划任务、固定文件快照和状态；既有目录、任务或
  重解析点一律拒绝覆盖。
- 动态槽在有效部署标记出现前返回 `DEPLOYMENT_REQUIRED`，不能启动占用活动入口。
- 代理产品版本由程序集读取，心跳不再使用手工固定版本字符串。

## 固定边界

- 动态槽只允许 `owl5 / activity / 127.0.0.1:25568 / owl5-activity-slot`。
- owl5 配置上限为 `12` 个动态槽，协议硬上限为 `16` 个。
- 代理不接受管理员指定路径、端口、任务名、Shell 或任意命令。
- 所有槽仍共享一个端口和冲突组，同一时刻最多运行一个；部署和创建都不会自动开服。

## 候选验证

- ServerControlAgent：`64/64`，覆盖成功、幂等重放、配置重载、已有目录/任务拒绝、
  安装失败回滚和取消回滚。
- 完整解决方案：`765/765`。
- PowerShell 7：`47` 个脚本解析通过；安装器会在替换代理前验证动态槽配置和任务安装
  脚本。
- owl5 SSH 只读核验确认：生产代理为 `0.5.0`，固定模板和任务安装器可用；现有活动
  Java 进程正在运行，正式升级必须只重启代理并证明 Java PID、启动时间和监听不变。

## 发布与回滚

1. 备份代理 EXE、配置、计划任务、canonical runner 和任务安装器。
2. 同步已验证的 canonical runner 与生产配置，再使用安装器原子替换代理并启动代理任务。
3. 验证 `0.6.0` 心跳、七个既有目标、动态槽能力和现有 Java 进程完全不变。
4. 失败时由安装器恢复旧 EXE、配置和任务；脚本文件单独恢复备份。不得重启或控制
   Minecraft。
