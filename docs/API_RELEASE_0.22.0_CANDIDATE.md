## 1. 变更

- 迁移 `018` 保留目标级协议转换开关，但所有既有目标默认关闭。
- 迁移 `019` 为服务器目录增加：
  - `server_role = Player | Infrastructure`；
  - `monitoring_enabled`。
- 历史 ID 或 Velocity 目标为 `lobby` 的记录自动变为 `Infrastructure`、
  `is_visible=false`、`allow_protocol_translation=false`、
  `monitoring_enabled=true`。
- 数据库约束禁止基础设施节点重新变为玩家可见或开启协议转换，并永久保护历史 Lobby
  角色。
- 玩家目录、档案下载资格、一次性进服授权、Velocity 目标解析和单服规则都只接受
  `Player` 角色。
- 心跳、TPS/MSPT/GC、运行状态与告警改用 `monitoring_enabled`，因此 Lobby 隐藏后仍
  继续监控。
- 管理后台显示“玩家服务器/内部基础设施”角色与监控开关，内部节点不能通过普通编辑
  恢复为玩家目标。

## 5. 回滚

程序直接回滚目标为生产 `0.20.2-20260727T225819Z`。迁移 `018/019` 为兼容性加列和
保护约束，旧程序可以忽略新列；但完整恢复旧数据库状态必须使用发布前一致性备份。

无论程序是否回滚，Lobby 都不能自动恢复为可见、可授权的玩家目标。若新版本失败，
优先保持 Lobby 隐藏并恢复旧 API 程序；监控缺口作为故障处理，不用重新开放大厅解决。
