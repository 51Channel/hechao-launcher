# Launcher API 0.32.0 独立部署槽候选

> 日期：2026-08-15
>
> 状态：候选已验证，尚未发布生产。

## 变更

- 新增迁移 `030_independent_deployment_slots.sql`，为动态槽记录用途、独立后端端口和独立 Velocity 目标。
- 后台可创建生存、活动、PVP、小游戏槽，对应 `survival-*`、`activity-*`、`pvp-*`、`minigame-*`，并显示实际端口。
- API 从 `25600-25611` 串行分配未占用端口。动态槽没有冲突组，固定 `activity / 25568 / owl5-activity-slot` 保持兼容。
- 整合包目录同步读取部署槽保存的权威 Velocity 目标；新独立槽使用自身 ID，旧共享活动槽
  继续使用 `activity`。
- Velocity 授权只为状态为 `Ready` 的动态槽返回 `127.0.0.1` 和批准端口。

## 安全与回滚

- 创建槽要求 owl5 代理至少为 `0.7.0`，旧代理不能领取独立端口命令。
- API 和代理分别校验端口池、ID 前缀、空冲突组、端口唯一性与真实监听占用。
- 新槽默认停止、隐藏，创建或部署都不自动启动 Minecraft；失败保留审计并回滚本轮资源。
- 迁移 030 是加法迁移。程序回滚时保留新增列和槽记录，不执行数据库降级。
- 迁移 030 保留既有共享活动槽的 `activity / 25568` 路由，不会仅因 API 升级而修改其
  主机端口、冲突组或 Minecraft 进程；旧槽转为独立用途时必须另做主机状态迁移和验收。
