真实客户端日志确认，玩家点击第三方屏幕按钮后，请求和服务端响应均正常：余额查询与出售

- 动作 ID、命令映射、短期会话、管理员权限和网络协议全部保持不变；
- 紧凑原版双列布局、窄窗口单列和矮窗口分页继续保持 `0.1.5` 的行为。
