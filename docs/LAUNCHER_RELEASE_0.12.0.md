## 1. 生产行为

- 赫朝启动器是唯一服务器选择与切换入口。
- 全局只允许一个由启动器管理的 Minecraft 进程。
- 切服时先请求现有游戏正常退出；旧进程完全退出后才申请新授权和启动新档案。
- 启动器重启后会按 PID、进程启动时间和可执行文件接管仍在运行的游戏。
- 在线目录、缓存目录和内置应急目录均过滤 `lobby`。
- 大厅仍作为 LuckPerms、指标、告警和备份等前置能力的内部承载器，但玩家、OP 和
  管理员均不得进入，也不得被用作默认回退。

## 5. 回滚

回滚到 `launcher-v0.11.16` 只替换启动器程序，不删除游戏数据、档案、受管 Java、
设置或 DPAPI 会话。即使启动器回滚，API 的基础设施角色、Velocity 拒绝和 Lobby
Guard 也必须继续生效，不能重新公开大厅。
