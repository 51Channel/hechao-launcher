# 启动器 0.11.10 小范围测试手册

> 范围：管理员本机与 2 至 3 名内部玩家
>
> 目标：验证运行配置布局修复，并回归 `0.11.9` 的真实游戏启动

## 安装前

- 只使用管理员提供的私有短时链接。
- 文件名必须为 `Hechao-Launcher-Setup-0.11.10-win-x64.exe`。
- 文件大小必须为 `61,819,393` 字节。
- SHA-256 必须为
  `4703FEF3113418BB13DBA86F097BE45D2C66BFD020774354117A0001FAA127AA`。
- 可以直接覆盖 `0.11.9`，不要删除客户端、Java 或游戏数据目录。

## 必测流程

1. 覆盖安装后确认版本显示 `0.11.10`，赫朝账号、Minecraft 绑定、内存和档案保留。
2. 在大厅、基础生存和活动档案之间切换，确认“自动 / 自定义”与六档内存按钮四边完整。
3. 缩小窗口并滚动服务器详情，确认控件不重叠、不裁切，路径保持单行省略。
4. 切换内存档位，关闭并重新打开启动器，确认每个选择正常保存。
5. 在兼容的自动 Java 和自定义 Java 之间切换，确认版本校验与档案隔离保持有效。
6. 使用基础档案进入服务器，确认 Minecraft 不在一秒内异常退出。
7. 使用活动 NeoForge 和 PVP Fabric 档案分别完成客户端检查；开放时再验证真实启动。
8. 中断一次下载后继续，删除一个受管文件后执行修复，确认当前完整版本不被提前替换。

## 回报内容

提供启动器版本、档案 ID、Windows 缩放比例、发生时间和玩家主动生成的脱敏诊断包。
不要发送 Microsoft 密码、浏览器地址栏、令牌、赫朝会话或私有下载链接。

## 通过条件

- Java 与内存选择器在常用窗口尺寸和 100%/125% 缩放下边框完整。
- 自动 Java、自定义 Java、内存和档案设置在重启后保持。
- 覆盖升级不清除账号、设置、客户端、存档或下载缓存。
- `0.11.9` 的安全目录、Fabric 类路径和异常处理没有回归。
- 启动失败时启动器保持运行并提供可诊断错误。
