## 修复范围

`0.11.3` 将账号页签边框统一向模板内部缩进 1 像素，但真实安装版中页签头部容器仍会裁掉右侧竖线，只保留左、上、下三边。`0.11.4` 将可见按钮间距移入页签槽位，并在安全区域内单独绘制右侧边线；选中、悬停和普通状态使用各自对应的边框颜色。
