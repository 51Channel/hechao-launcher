## 修复范围

`0.11.5` 将账号页签改为与游戏内存选项相同的等宽完整矩形，但页签标题的居中属性同时作用到了选中内容，导致登录和注册表单按最小宽度排列。该版本只在本机安装检查，未上传、未打标签，也未向玩家分发。

`0.11.6` 将标题与内容对齐分开处理：

- 登录和注册标题继续在两个等宽按钮中居中显示。
- 两个按钮均使用完整四边框，选中状态为浅红底与红色边框。
- 选中内容宿主明确横向、纵向拉伸。
- 登录输入框、密码框和主按钮恢复整栏宽度。
- 注册页用户名、显示名称、邮箱、验证码、密码和主按钮恢复原有网格布局。

## 验收证据

- 真实 WPF 渲染测试覆盖登录和注册两种选中状态。
- 测试确认两个页签等宽、边框与可见按钮外沿重合，左右竖边间距等于按钮物理宽度。
- 新增表单回归断言，选中内容宽度必须等于 `TabControl` 整栏宽度，不能退回内容最小宽度。
