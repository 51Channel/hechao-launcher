# API 0.28.3 发布候选

## 修复范围

- 整合包“等待确认”页面在检查活动部署槽时显式包含已经删除服务端目录的目标；
- 已删除但仍保留代理配置和部署能力的 `activity` 目标，不再误报“服控代理”离线或
  “目标已停服”未满足；
- 普通服控面板继续隐藏目录不存在、清理完成且没有活动操作的目标，不恢复已删除服务端
  的日常列表记录；
- 服务端重新部署后仍按既有心跳和目录状态自动恢复到普通服控列表。

根因是整合包页和普通服控页共用同一个概览接口。API `0.28.1` 隐藏已完成删除目标后，
整合包页也无法读取仍可重新部署的固定活动槽，因此把目标缺失误判为代理离线。

## 候选验证

- 后端可见性聚焦测试 `5/5`；
- TypeScript 和 Vite 生产构建通过；
- Vitest `8/8`；
- Playwright `16/16`；
- 聚焦浏览器回归确认目录不存在的 `activity` 目标仍显示服控代理在线、目标已停服，
  并可提交重新部署；
- API `283/283`、完整解决方案 `.NET 671/671`；
- Impeccable detector 无问题；
- 差异敏感信息扫描和 `git diff --check` 通过；
- NuGet 漏洞数据源超时仅产生 `NU1900`，所有项目编译和测试成功，未修改依赖。

## 发布与回滚

本版本没有数据库迁移，不升级 VPS 代理，只发布 API `0.28.3`。部署只允许重启
`hechao-launcher-api.service`，不得操作 Minecraft、Velocity、Publisher 或两台
ServerControlAgent。

生产已经存在 `DeleteServerFiles` 操作记录，不能回滚到 `0.27.3`。本版本的直接安全
回滚目标是 API `0.28.2`；readiness 失败时安装器必须自动恢复该版本。
