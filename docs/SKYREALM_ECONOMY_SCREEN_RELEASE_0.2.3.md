## 本轮修复

### 玩家市场上架

- 上架页的规则说明固定在顶部输入区，不再画入玩家背包区域，避免和背包槽位重叠；
- 仅显示上架物品槽与玩家背包槽，隐藏服务端控制槽不再产生悬浮提示；
- 拦截隐藏控制槽的原版容器点击，确认上架、返回和物品交互仍通过既有服务端裁决；
- 价格输入继续使用客户端格式校验，最低价格、手续费、库存和权限仍由服务端最终判断。

### 我的队伍

- 常见窗口尺寸显示最多 6 名成员的可点击列表，点击成员会填入玩家操作框；
- 队长不能被客户端误操作为“移出成员”，其他移出操作继续要求二次确认；
- 队伍页保留邀请、接受邀请、离队、队伍聊天、刷新和返回首页；
- 兼容 `队伍成员: [队长] 玩家, 成员` 与 `队长: 玩家，成员: 玩家` 两类服务端文本；
- 窄窗口仍保留手动输入方式，不依赖成员列表按钮。

客户端继续只发送已有命令：

```text
skyrealmcore:team list
skyrealmcore:team invite <player>
skyrealmcore:team accept
skyrealmcore:team kick <player>
skyrealmcore:team leave
skyrealmcore:team chat <message>
```

本轮没有假设或新增队长转移、解散等未在当前 SkyrealmCore 交接资料中确认的命令。
