## 变化

- 运行配置新增“回滚版本”，只在存在有效上一版时启用。
- 对应 Minecraft 仍在运行、安装或修复正在进行时禁止回滚。
- 回滚先以硬链接优先方式克隆上一版，再将当前存档、截图、资源包、光影、
  日志、设置和服务器列表覆盖到暂存副本，最后执行原子目录交换。
- 回滚后的原当前版继续保留为新的 `.previous`，可以再次切换或更新。
- 切换失败时恢复当前版与上一版；极端恢复失败时保留暂存副本，不主动删除
  最后一个可恢复版本。
- 回滚后重新验证档案 Java；Java 补齐失败时保留已切换版本并引导使用修复。
- 原子切换器会隔离切换瞬间意外出现的目标目录，再恢复当前版和上一版。
- 增加私有安装包短时链接下载验证脚本，验证过程不回显签名 URL。

## 回滚

若灰度发现独立阻断，关闭启动器后使用 `0.11.10` 覆盖安装。程序覆盖不会删除赫朝
会话、设置、客户端、受管 Java、下载缓存或世界存档。玩家端“回滚版本”只回滚
所选 Minecraft 客户端档案，不会回滚启动器程序本身。
