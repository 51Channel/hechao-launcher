## 修复范围

`0.1.7` 的余额结果页、出售报价页和回收目录会把面板、标题和业务文字一起模糊，原版
按钮却保持清晰。根因不是字体、GUI 缩放或截图压缩，而是自定义页面先调用一次
`renderBackground`，绘制业务内容后又调用 `Screen.render`；Minecraft `1.21.1` 的
`Screen.render` 会再次执行背景模糊，再在其后绘制原版 Widget，因此形成了截图中的
精确边界。

`0.1.8` 增加不可被页面覆盖的单次背景渲染管线，并让三个页面统一按以下顺序渲染：

1. 世界背景与菜单模糊只执行一次；
2. 绘制自定义面板、标题、结果和商品卡片；
3. 绘制原版按钮和其他 Widget，不再触发第二次背景处理；
4. 最后绘制商品 Tooltip，避免悬浮提示被按钮或面板遮挡。

页面业务、按钮命令、服务端授权、出售确认、商品目录和网络协议均未改变。生产商品表
仍为 `0` 条，没有启用文档中的 `85` 项待审核候选。

`1.0.17` 再进行。
