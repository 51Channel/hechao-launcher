## 发布边界

- 不覆盖 `0.15.7` 对象或标签；正式对象固定为
  `releases/launcher/0.15.8/Hechao-Launcher-Setup-0.15.8-win-x64.exe`。
- 最低支持版本保持 `0.12.3`，不扩大强制更新边界。
- 更新通道切换只允许再次重启 `hechao-launcher-api.service`；不得重启 Publisher、
  Nginx、Velocity、服控代理或任何 Minecraft 服务端。
- 当前活动未进入开放窗口，最终真实进服拒绝保留到开放窗口真人验收；候选不能把目录
  `canJoin` 当成服务端最终授权。

## 回滚

分发异常时恢复切换前 API 环境备份并只重启 Launcher API，或禁用启动器更新通道。
已经安装 `0.15.8` 的客户端不会自动降级；修复必须发布更高版本，不能覆盖本对象。
