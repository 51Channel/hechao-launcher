## 修复范围

`0.1.6` 只在按钮关闭前显示 ActionBar，余额、出售结果仍进入聊天栏，回收目录仍使用
Bukkit 箱子界面。`0.1.7` 将三项玩家高频动作改为模组原生业务界面：

- 余额查询在当前游戏画面上打开加载页，并直接显示服务端返回的余额或错误；
- 出售主手先显示服务端报价，仅在收到有效“报价:”响应后显示“确认出售”，确认动作仍
  发送固定命令 `hechaoeconomy:sell confirm`；
- 回收目录接管标题为“赫朝回收目录”的服务端容器，显示物品图标、名称、回收价、悬浮
  提示、空状态、分页按钮和滚轮翻页；
- 常见 `512 x 270` GUI 使用三列、每页十二项，`320 x 180` 使用两列、每页四项，
  `200 x 140` 使用单列、每页一项；
- 结果页区分加载、成功和失败，最多保留六条结果，并在 `200 tick` 无响应后显示超时；
- 服主回收设置、个人设置和队伍仍沿用既有 ActionBar 与服务端命令行为。

服务端继续负责授权、短期会话、报价、确认出售和商品目录。客户端不生成价格、不放宽权限，
动作 ID、命令映射和协议均未改变。当前生产商品目录仍为空，未启用任何待审核商品。
