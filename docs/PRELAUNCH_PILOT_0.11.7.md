# 启动器 0.11.7 小范围测试手册

> 范围：2 至 3 名内部玩家
>
> 目标：验证 Microsoft 游戏凭据自动刷新修复，不启用目录强制登录或 Velocity
> `enforce`

## 安装前

- 只使用管理员提供的私有短时链接。
- 文件名必须为 `Hechao-Launcher-Setup-0.11.7-win-x64.exe`。
- 文件大小必须为 `61,805,936` 字节。
- SHA-256 必须为
  `9215849E914C125D827CF86D104D5FFEF865840AEEE6F31A0DC2DA6F1B1819EA`。
- 可以直接覆盖 `0.11.6`，不得删除游戏数据目录。

## 必测流程

1. 登录已有赫朝账号，确认账户页仍显示原 Minecraft 玩家和 LuckPerms 等级。
2. 选择已安装且在线的服务器，点击“进入服务器”。
3. 若系统浏览器打开，选择与账户页已绑定玩家对应的 Microsoft 账号。
4. 浏览器认证完成后返回启动器，确认无需再次点击即可继续启动 Minecraft。
5. 取消一次浏览器认证，确认启动器仍保持运行且游戏没有启动。
6. 有第二个正版账号时故意选错一次，确认界面显示账号不匹配且现有绑定不变。
7. 再使用正确账号进入大厅，验证目标服、NPC 转服、`/hub` 和断线重连。

## 回报内容

只提供启动器版本、发生时间、服务器名、界面简短错误和玩家主动生成的脱敏诊断包。
不要提交 Microsoft 密码、浏览器地址栏、令牌、赫朝会话或私有下载链接。

## 通过条件

- 旧游戏凭据失效后会自动打开浏览器，不再提示退出赫朝账号。
- 正确账号完成认证后自动继续启动。
- 取消、选错账号和网络失败均不闪退、不改绑、不启动 Minecraft。
- 既有客户端、设置和游戏数据保持不变。
