## 故障边界

| 场景 | 已验证行为 |
| --- | --- |
| 断网或瞬时失败 | 续传已有分片、刷新过期重定向、限次重试；对象服务不可用时保留当前客户端；取消重新登录不会闪退 |
| 文件损坏 | 错误摘要立即拒绝，受管文件可修复，签名清单摘要不匹配时拒绝激活，上一可用版本保留 |
| 服务器维护 | 手动维护或关闭优先于心跳和显式允许，Velocity 仍拒绝进入 |
| 权限变化 | 停用、显式拒绝、快照过期和等级不足均由服务端拒绝，客户端状态不能绕过 |
| 版本回滚 | 上一版本原子激活并保留玩家数据；并发安装、无效候选和运行中客户端均阻止；切换失败恢复两边目录 |
