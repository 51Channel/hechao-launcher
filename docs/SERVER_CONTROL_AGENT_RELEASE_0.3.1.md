## 修复范围

`0.3.0` 的心跳和命令循环相互独立，但心跳仍会在整合包切换期间读取活动目录中的配置
和控制台尾部。Windows 可能因短时子文件句柄拒绝父目录重命名。`0.3.1` 完成以下修复：

- 每个目标增加异步目录访问门闩，串行化心跳快照、快捷设置事务和目录恢复/切换；
- 下载、摘要校验和暂存解压不持有门闩，不长期阻塞全机心跳；
- 配置读取允许读写与删除共享；
- 目录和固定文件移动只对共享冲突、锁定和父目录占用做
  `50/100/200/400/800 ms` 有界重试；
- 外部进程持续占用时保持失败关闭，并进入既有自动回滚，不终止未知进程。
