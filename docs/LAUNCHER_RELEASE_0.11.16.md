## 变化

- Minecraft 进程退出后，当前档案会立即从“游戏已启动”恢复为“游戏已退出”或
  “游戏异常退出”，主操作按钮同步恢复。
- 同一档案快速重新启动时，旧进程延迟到达的退出事件不会覆盖新进程的运行状态。
- 新增私有启动器制品复验脚本。脚本只从管理员 ACL 保护文件中读取短时链接，
  校验固定 HTTPS 主机与对象路径、匿名 `403`、签名下载状态、长度和 SHA-256，
  临时文件在成功或失败后都会删除，且不会输出私有链接。

## 回滚

若灰度发现独立阻断，关闭启动器后使用 `0.11.15` 覆盖安装。覆盖不会删除赫朝会话、
设置、客户端、受管 Java、下载缓存或世界存档。升级前的真实 `settings.json` 和
`session.dat` 另存于本机升级备份目录，可用于核验；不得把 DPAPI 会话文件复制到
其他 Windows 用户或设备。

## 边界

本次启动器制品只修复 Minecraft 退出后的界面状态并增加管理员侧私有制品复验工具，
不修改 API、数据库、Velocity、客户端档案或服务器目录。生产 API 仍为 `0.20.2`，
生产 Velocity Authorizer 仍为 `0.3.0 monitor`，跨版本回程候选继续只在隔离环境
验证，不因本安装包发布而进入生产。
