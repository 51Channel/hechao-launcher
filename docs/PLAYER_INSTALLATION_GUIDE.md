# 赫朝启动器玩家安装指南

> 适用平台：Windows 10/11 64 位
> 当前启动器私有 OSS 灰度版本：`0.12.2`
> 当前状态：私有 OSS 内部灰度候选，尚未向玩家公开分发

## 1. 安装前准备

安装前请确认：

- 拥有可以正常游玩 Minecraft: Java Edition 的 Microsoft 账号。
- 系统盘或所选游戏数据盘至少保留 8 GB 可用空间；安装多个活动档案时需要更多空间。
- 可以访问赫朝官网、启动器 API、Microsoft 登录页和 Minecraft 官方服务。
- 已退出正在运行的 Minecraft、旧版赫朝启动器和其他正在修改同一游戏目录的工具。

只从赫朝官网或管理员正式公告中的链接下载安装包。正式公告必须同时给出文件名、版本、大小和 SHA-256；来源不明或哈希不一致的安装包不要运行。

当前版本没有 Windows 代码签名证书，首次运行时 SmartScreen 可能显示“Windows 已保护你的电脑”。这不代表文件一定有问题，但只有在下载来源正确且 SHA-256 与正式公告完全一致时，才可以选择“更多信息”继续运行。

## 2. 安装启动器

1. 运行 `Hechao-Launcher-Setup-<版本>-win-x64.exe`。
2. 按安装向导完成当前用户安装；一般不需要管理员权限。
3. 程序默认安装到 `%LocalAppData%\Programs\Hechao Launcher`。
4. 从开始菜单或桌面快捷方式打开“赫朝启动器”。

启动器程序与游戏数据分开保存。默认游戏数据位于 `%LocalAppData%\Hechao\GameData`，更新或卸载启动器不会自动删除世界、截图、资源包和已下载档案。

## 3. 登录与绑定正版账号

1. 在“账户”页注册或登录赫朝账号。
2. 选择绑定 Microsoft/Minecraft 正版身份。
3. 启动器会打开系统浏览器；Microsoft 密码只在 Microsoft 页面输入，不要发给赫朝管理员。
4. 浏览器显示“Authentication complete”时，直接关闭该标签页并回到启动器。
5. 启动器显示 Minecraft 名称和赫朝等级后，绑定完成。

若启动器仍显示“访客”，先等待数秒或重新进入账户页。不要反复快速点击登录；确认浏览器完成页已经出现、系统时间正确，并检查是否有防火墙阻止本机回调。

点击“进入服务器”时，如果本机 Microsoft 游戏凭据已过期，启动器会自动再次打开系统浏览器。选择与赫朝账号已绑定 Minecraft 玩家对应的 Microsoft 账号；认证成功后启动器会自动继续启动游戏，不需要退出赫朝账号或再次点击“进入服务器”。若选错账号，启动器会显示两个 Minecraft 玩家名并停止启动，不会修改现有绑定。

Minecraft Java API 许可已经通过，正式正版绑定进入生产验收阶段。若仍看到应用未批准或绑定失败，请保留启动器中的简短错误并联系管理员；不要尝试第三方 Client ID、共享令牌或非官方登录补丁。

## 4. 安装服务器客户端

1. 在“服务器”页选择要进入的服务器。
2. 首次进入某个档案时选择“安装客户端”。
3. 保持启动器运行，等待获取清单、下载、校验、切换版本和安装配套 Java 全部完成。
4. 显示“客户端已就绪”后再选择“进入服务器”。

大厅、生存服和不同活动服可以使用不同客户端档案。每个档案都有独立的 `.minecraft` 和配套 Java，Forge、Fabric、NeoForge、原版文件及不同 Java 主版本不会互相混用；已下载对象仍会安全共享以减少重复下载。

下载可以断点续传。关闭启动器或网络中断后，重新打开并继续即可；不要手工改名或执行未校验的 `.part` 文件。

`0.11.2` 会并行下载小文件，并在临时限流或网络中断后自动等待和续传。登录与目录请求仍按 Windows 网络设置工作，游戏资源会优先直连分发节点；不需要玩家关闭代理、杀毒软件或系统防护。

`0.11.3` 会让下载进度条平滑跟随真实进度；关闭系统动画时自动改为即时更新。界面动画不会改变实际下载量、速度、断点续传或文件校验结果。

`0.11.4` 修正账号页登录/注册页签右侧边框在部分 Windows 缩放比例下缺失的问题，不改变账号、密码、正版绑定或论坛同步流程。

`0.11.6` 将登录和注册选择器改为与游戏内存选项相同的等宽完整矩形，同时保持两个表单横向铺满卡片。未改变账号、密码、邮箱验证、正版绑定或论坛同步流程。

`0.11.7` 修正“退出赫朝账号后重新登录”无法刷新 Minecraft 游戏凭据的问题。赫朝社区登录与 Microsoft 游戏登录继续保持独立；游戏凭据需要交互续期时由启动器直接打开 Microsoft 页面。

`0.11.8` 会在首次安装或修复客户端时，把该档案适用的 Java 一并安装到游戏数据目录。运行配置默认选择“自动”；需要使用自己安装的 Java 时，可以为当前客户端档案单独选择 `java.exe` 或 `javaw.exe`。启动器会先检查版本，例如 1.21.11 档案要求 Java 21、PVP 1.20.1 档案要求 Java 17，不兼容的文件不会保存。切换回“自动”即可恢复启动器下载的 Java。

`0.11.9` 修复自定义游戏数据目录含不可见格式字符时，Java 能启动但 Fabric Loader 类路径仍失效的问题。若 `0.11.8` 点击进入服务器后立即异常退出，应直接覆盖安装 `0.11.9`；不需要重新下载客户端或 Java。

`0.11.10` 调整“运行配置”侧栏：Java 的“自动 / 自定义”和内存档位使用一致的全宽分段布局，选中项四边边框在窄窗口下也会完整显示。此变更不修改已有 Java 选择、内存值、客户端文件或账号状态。

`0.11.11` 在运行配置底部增加“回滚版本”。只有启动器保留了有效上一版、当前没有安装任务且对应 Minecraft 已退出时按钮才可用。确认回滚后，当前存档、截图、资源包、光影、设置和服务器列表会带入上一版；目录仍发布新版本时，主按钮会显示“更新客户端”，可随时重新更新。

`0.11.14` 让“启动时检查客户端更新”开关真正生效。关闭后启动器首次打开不会自动
扫描所选客户端，状态会显示“启动检查已关闭”；点击“检查客户端”或第一次尝试进入
服务器时仍会先检查，不能跳过版本和完整性验证。重新开启开关会立即检查当前档案。

`0.11.15` 会在启动游戏前补齐并校验 Minecraft 版本元数据声明的日志配置文件。
若 `assets/log_configs/*.xml` 缺失或损坏，启动器会自动恢复后再继续启动；玩家不再
需要手工复制该文件。

## 5. 旧版数据迁移

启动器首次运行时会识别旧 `%AppData%\Hechao\instances` 或以前设置的自定义目录，并迁移到新的档案结构。

- 迁移完成前不要删除旧目录。
- 迁移失败时原文件会保留，启动器不会静默切换到空目录。
- 遇到“游戏数据迁移未完成”时，记录提示内容并联系管理员，不要反复移动整个目录。
- 更换游戏数据目录只影响之后使用的位置，不会在界面中自动搬运已有的数 GB 数据。

## 6. 更新与修复

启动器会校验已发布清单和本地文件：

- 普通更新只下载新增或变化的内容。
- “修复客户端”会重新检查受管文件并补齐损坏内容。
- 更新在独立暂存目录完成后才会切换；失败时继续保留当前可用版本。
- “回滚版本”会先克隆上一版再原子交换；切换失败时恢复当前版和上一版，不在运行中的 Minecraft 目录上强行操作。
- 玩家世界、截图、资源包、光影包和常用选项不会因为修复被清空。

遇到启动失败、模组缺失或文件校验失败时，先退出游戏，再使用“修复客户端”。不要先删除整个 `.minecraft`，否则会丢失本地日志和可用于定位问题的信息。

## 7. 常见问题

### 服务器没有显示

服务器可能处于维护、未开放，或当前赫朝等级不满足最低权限。客户端列表只是展示层，最终进服仍会由 Velocity 再次校验。

### 下载停住或反复失败

先等待启动器自动重试，再检查网络、剩余磁盘空间和系统时间。关闭后重新打开不会丢失已完成对象；仍失败时使用“修复客户端”并生成诊断包，不要手工删除 `shared\objects`。

### 点击进入后没有启动游戏

确认客户端显示已就绪、目标服务器在线，并检查设置中的游戏内存。若浏览器被打开，请完成 Microsoft 正版认证并返回启动器；不要通过反复退出赫朝账号来刷新游戏凭据。若提示自定义 Java 不兼容，在当前服务器的运行配置中恢复“自动”或重新选择正确主版本。不要把全部物理内存分配给 Minecraft。

### 杀毒软件拦截更新

先核对安装包来源和 SHA-256。不要直接关闭系统防护；把拦截提示和诊断包交给管理员确认。

### 活动服与大厅模组不同

这是正常的档案隔离。必须从启动器选择对应服务器，让启动器自动准备正确的 Fabric、Forge 或 NeoForge 客户端，不要把模组手工复制到其他档案。

## 8. 诊断与隐私

设置页可以由玩家主动生成本地诊断包。诊断包不会自动上传，也不应包含 Microsoft 密码、赫朝密码、访问令牌、世界存档或完整设备标识。

提交问题时提供：

- 启动器版本。
- 服务器名称和发生时间。
- 界面显示的简短错误。
- 玩家主动生成的诊断 ZIP。

不要发送 Microsoft 登录完成页的地址栏、浏览器令牌、赫朝会话、服务器密码、SSH 密钥或云 AccessKey。

## 9. 升级与卸载

新版本安装包可以直接覆盖升级，设置和游戏数据会保留。卸载器只删除启动器程序和快捷方式，不删除：

```text
%LocalAppData%\Hechao\GameData
%LocalAppData%\Hechao\Launcher
```

需要彻底删除游戏数据时，先确认世界、截图和资源包已经备份，再由玩家自行删除上述目录。
