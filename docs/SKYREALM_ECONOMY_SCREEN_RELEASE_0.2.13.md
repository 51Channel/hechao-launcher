- 玩家在安全落点查找完成前再次请求时，仍由活动请求表拒绝，不会并发创建区块请求；
- 查找失败、超时、掉线、死亡或换维度时继续释放冷却，允许重新尝试；

  `30` 秒和已加载区块安全检查均未改变；
- 网络负载、菜单 UI 和协议未修改，客户端档案无需更新，玩家不需要重新下载客户端。
