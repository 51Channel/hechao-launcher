# 赫朝启动器 0.15.3 候选发布记录

- 候选日期：2026-08-09
- 上一正式版本：`0.15.2`
- 功能来源提交：`2b00f10`、`5ff4d59`
- 目标正式标签：`launcher-v0.15.3`

## 发布范围

1. 主页内存下拉弹层移除容易被 WPF Popup 边界裁切的投影，改为单一清晰边框。
2. 下拉项复用启动器统一焦点样式，替换系统默认虚线框，同时保持完整键盘操作。
3. “查看活动”按钮覆盖基础按钮的 `38px` 最小高度，以 `32px` 在 `34px` 标题行中
   垂直居中，避免底边裁切。
4. 账号头像、显示名、登录状态、访问身份和账户操作从服务器目录底部移到最左侧导航栏
   底部；中间目录恢复为完整可滚动服务器列表，账号绑定和命令保持不变。
5. 当前服务器横幅、详情、状态信息、主操作和三点菜单合并到一个跨两列的连续主卡片，
   移除图片与详情之间的外层卡片间隙，不增加虚假数据或新操作。
6. 服务器目录、客户端下载、自更新、账号、活动日历和游戏启动逻辑保持不变。

## 发布边界

- 不改变活动目录、客户端档案、服务器开放状态、官网内容或后台业务数据。
- 不启动、停止或重启 Minecraft、Velocity、服控代理或常驻 Publisher Agent。
- 生产切换只新增私有 OSS 不可变安装包并更新 Launcher API 的启动器版本元数据；切换前
  备份 API 环境文件，任一验收失败立即恢复。
- 最低支持版本保持 `0.12.3`，不扩大强制更新边界。

## 回滚

发布失败时保持 `LatestVersion=0.15.2`。切换后若发现分发异常，恢复 API 环境备份或
关闭 `LauncherUpdates__Enabled`，再只重启 Launcher API。已经安装 `0.15.3` 的客户端
不会自动降级；代码修复继续使用更高版本，禁止覆盖任何已上传对象或既有标签。
