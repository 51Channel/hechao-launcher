# API 0.28.5 发布候选

## 范围

- 数据库迁移 `025` 为服控目标保存代理上报的 VPS 物理内存；旧代理未上报时保持空值，
  不伪造容量。
- 整合包后台显示 VPS 总内存、推荐最小内存和推荐最大内存。
- 推荐区间只做提示；管理员填写低于或高于建议区间的合法值时，确认按钮保持可用。
- 删除 API 确认接口和部署编排中的 `4096 MiB` 回退上限与内存上限变化门禁。
- 最大内存仍必须是 `1-64 GiB` 范围内的 `256 MiB` 整数倍，防止无效结构化命令。

## 验证

- API `287/287`；
- 完整解决方案 `.NET 680/680`；
- TypeScript 与 Vite 生产构建通过；
- Vitest `8/8`；
- Playwright `16/16`，包含 `32 GiB` VPS、推荐 `4-16 GiB`、管理员填写
  `20 GiB` 后仍可提交的回归；
- Impeccable 检测零项。

## 部署边界

- 必须先部署 API `0.28.5` 并完成迁移 `25/25`，再升级 owl5 代理 `0.4.1`；
- API 切换失败自动回滚到 `0.28.4`；迁移 `025` 为可空新增列，无破坏性改写；
- 代理安装失败恢复旧 EXE、配置和计划任务；
- 不启动、停止、重启或控制 Minecraft、Velocity、Publisher；
- 不替管理员提交现有整合包任务。
