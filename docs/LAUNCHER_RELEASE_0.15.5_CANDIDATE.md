1. 左侧导航改为内容驱动，账户与社区声明紧跟五个导航项；高窗口的多余空间落在声明
   下方，不再把账户面板压到窗口底边。
2. 服务器目录按真实条目数量收口，列表超过上限后内部滚动，不再保留贯穿窗口的空白
   面板。
3. 当前服务器、公告/近期活动和快捷设置固定为 `236 / 200 / 112` 的稳定纵向节奏；高
   窗口只增加页面底部画布留白，不拉伸业务卡片。
4. 当前服务器主操作紧跟详情信息，不再固定贴住卡片底边。
5. 快捷设置重做为 Java、运行内存和当前 `.minecraft` 三个有边界的字段组；所有原有
   绑定、命令、路径省略和打开目录能力保持不变。
