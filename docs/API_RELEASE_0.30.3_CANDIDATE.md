# API 0.30.3 候选发布

- 候选版本：`0.30.3`
- 配套组件：`HechaoLuckPermsTierAgent 0.1.3`
- 数据库迁移：无，保持 `028`
- 状态：API `311/311`、完整解决方案 `731/731` 通过，尚未正式部署

## 范围

本版本只收紧内部 LuckPerms 等级命令端点：

- `claim` 和 `complete` 必须携带语义化代理版本及协议 `2`；
- 旧代理缺少新增字段时返回输入验证错误，不会领取、续租或完成命令；
- `claimed_by` 使用版本化身份，完成回执必须与领取时的软件版本和协议一致；
- 完成审计增加 `AgentVersion` 和 `ProtocolVersion`；
- 不修改后台玩家操作、身份映射、快照导入、Launcher、活动、分发或服控合同。

## 发布边界

应先让内部大厅加载 `0.1.3`，再使用标准 Linux 原子发布脚本切换 API。发布只允许重启
`hechao-launcher-api.service`；不得操作 Nginx、Publisher、Velocity、生存服或活动服。

生产切换前必须完成数据库 custom-format 备份、API 环境与当前 release 备份、制品哈希
复核及无活动命令检查。部署后验证本机/公网健康、旧协议 `400`、协议 `2` 空领取 `200`、
API warning/error、服务重启计数和两轮五分钟快照。

程序回滚目标为当前不可变 `0.30.2` release。回滚不会撤销已禁用的遗留 staging 任务；
在 API 回滚期间，正式 `0.1.3` 仍可兼容 `0.30.2`，但旧协议门禁会暂时失去服务端保护。
