## 总体门禁

- 价格是每个物品的官方回收单价，支持两位小数。
- 每名玩家所有官方回收商品合计最多获得 `5,000.00` 金币/日。
- 全服所有官方回收合计最多铸造 `100,000.00` 金币/日。
- 每个商品还同时受表内个人日限和全服日限约束；全服日限统一为个人日限的 `20` 倍。
- 一次出售超过剩余额度时，只回收额度内数量，其余物品保留在玩家背包。
- 额度日按 `Asia/Shanghai` 每天 `00:00` 重置。当前 API 使用 UTC 日期、北京时间
  `08:00` 重置，正式采用本表前必须修正。
- 当前代码没有个人跨商品总额和全服跨商品总额门禁，正式采用本表前必须实现并完成并发测试。
