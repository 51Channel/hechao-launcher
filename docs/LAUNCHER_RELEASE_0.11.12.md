## 变化

- 玩家生成脱敏诊断包后，可以在设置页主动选择“上传诊断包”。
- 上传前显示独立确认框，明确说明不包含世界存档、账号密码或会话令牌，
  服务端最多保存 14 天，管理员下载会记录审计。
- 上传入口只接受启动器刚生成、大小未变化、非重解析点的 ZIP，并在上传前
  重新计算 SHA-256。
- 创建上传授权时沿用赫朝会话；遇到过期访问令牌会刷新一次再重试。
- 诊断文件使用独立五分钟 HTTP 客户端流式上传，不会阻塞界面线程。
- 上传失败、取消、鉴权失效或网络错误只更新页面状态，不会退出启动器。
- 增加真实 Minecraft 启动构建回归，覆盖自动 Java 与自定义 Java 路径。

## 回滚

若灰度发现独立阻断，关闭启动器后使用 `0.11.11` 覆盖安装。程序覆盖不会删除
赫朝会话、设置、客户端、受管 Java、下载缓存或世界存档。玩家已经上传的诊断包
由服务端按原到期时间管理，回滚客户端不会延长其保存期。
