# API 0.28.2 发布候选

## 修复范围

- 整合包“等待确认”表单把精确确认文本纳入本地草稿快照；
- 后台每 3 秒刷新任务、发布代理和活动部署槽状态时，不再清空管理员正在输入的确认文本；
- 其他表单字段继续使用既有脏数据保护，服务器状态和任务状态仍可自动刷新；
- 确认提交、修订冲突、关闭抽屉和切换任务的既有边界不变。

根因是草稿序列化遗漏 `confirmation` 字段。只编辑该字段时，页面错误地认为表单没有
修改，并在下一次轮询中重新初始化表单。

## 发布与回滚

本版本没有数据库迁移，不升级 VPS 代理，只发布 API `0.28.2`。部署只允许重启
`hechao-launcher-api.service`，不得操作 Minecraft、Velocity、Publisher 或两台
ServerControlAgent。

生产已经存在 `DeleteServerFiles` 操作记录，不能回滚到 `0.27.3`。本版本的直接安全
回滚目标是 API `0.28.1`；readiness 失败时安装器必须自动恢复该版本。
