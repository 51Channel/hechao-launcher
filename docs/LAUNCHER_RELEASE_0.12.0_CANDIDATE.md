## 1. 变更

- 赫朝启动器成为唯一服务器选择与切换入口。
- 全局只允许一个由启动器管理的 Minecraft 进程，不再按档案分别判断。
- 运行状态写入
  `%LocalAppData%\Hechao\Launcher\running-game.json`；启动器重启后按 PID、进程启动时间
  和可执行文件重新接管仍在运行的游戏。
- 切换服务器时先请求当前 Minecraft 窗口正常关闭，最多等待 15 秒；超时后才结束进程
  树。旧进程未完全退出时，不申请新目标授权，也不创建新进程。
- 同目标显示“重新连接”，不同目标显示“切换服务器”；预期停止或强制收口不再显示为
  游戏崩溃。
- 生产目录、缓存目录和内置应急目录都会过滤历史 `lobby` 目标；默认服务器 ID 改为空，
  不再把大厅当作启动器默认项。
