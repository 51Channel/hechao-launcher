# 天域远征工业季首发回收目录 v1

- 状态：待服主审核，未部署
- 适用服务器：`activity-survival`
- 货币：金币，保留两位小数
- 目标规模：约 20 名玩家
- 额度单位：物品数量/自然日，不是金币金额
- 制表日期：2026-08-17
- ID 核验：Minecraft `1.21.1`、Create `6.0.10`、Farmer's Delight `1.3.2` 生产 JAR

## 定价原则

1. A 阶段先开放采矿资源，用 `2/3/5` 人灰度验证报价、库存扣除、账本和额度。
2. B 阶段再开放可再生作物和怪物掉落；这些物品容易自动化，因此单价低、额度更严格。
3. 全服日限统一按个人日限的 20 倍设置，覆盖约 20 人活动规模并限制多账号与自动化总产出。
4. 首版不回收锭、粒、压缩块、矿物粉碎物、金属板、黄铜、机器、工具、装备和料理，避免配方换算与耐久数据造成套利。
5. 表中金额是首发基线，不承诺永久价格。只根据真实成交量调整，不按玩家口头报价临时修改。

## 首版明确不收

- `create:crushed_raw_*`、锭、粒、储存块、金属板、黄铜和其他加工产物；
- Farmer's Delight 料理、切片、面团、酱料、厨具和容器；
- 原版及模组工具、武器、护甲、机器、功能方块和结构战利品；
- 木材、圆石、泥土、沙子、竹子、仙人掌等超低门槛或可无限自动化方块；
- 任何改名、附魔、带 Lore、耐久变化、容器内容或其他 ItemMeta 的物品。

## 上线门禁

1. 先只配置 A 阶段，并用 `/shop` 核对 11 个 ID、价格和额度。
2. 使用普通账号分别完成报价、确认、超额拒绝、重复确认和失败补偿。
3. 观察至少一个自然日的商品流水和总发币量，再决定是否启用 B 阶段。
4. B 阶段启用后重点监控 Create 自动农场和刷怪塔；出现异常先停用单项商品。
5. 第一次正式成交前保留数据库备份；后续回滚只停用商品，不删除账本和审计记录。
