# 启动器 0.11.8 小范围测试手册

> 范围：2 至 3 名内部玩家
>
> 目标：验证每档案 Java 自动安装、自定义选择和旧版本覆盖升级；不启用目录强制登录
> 或 Velocity `enforce`

## 安装前

- 只使用管理员提供的私有短时链接。
- 文件名必须为 `Hechao-Launcher-Setup-0.11.8-win-x64.exe`。
- 文件大小必须为 `61,816,090` 字节。
- SHA-256 必须为
  `778F9F69439386E60CF5BEFA25BF7448EE4EAF92A05447EBB0A97553F5047BC0`。
- 可以直接覆盖 `0.11.7`，不得删除游戏数据目录。

## 必测流程

1. 覆盖安装后确认赫朝账号、Minecraft 绑定、所选服务器、内存和游戏目录仍保留。
2. 选择基础客户端，确认运行配置显示 Java 21、Java 使用为“自动”。
3. 对尚未完成 Java 准备的档案执行安装或修复，确认进度末段显示正在安装配套 Java，
   完成后客户端才变为就绪。
4. 选择 PVP 1.20.1，确认显示 Java 17，并且运行时路径与基础客户端不同。
5. 为 PVP 故意选择 Java 21，确认启动器提示需要 Java 17且不保存该选择。
6. 为一个档案选择兼容的自定义 Java，切换到其他服务器再返回，确认选择仍保留且
   不影响其他档案。
7. 切回“自动”，确认路径恢复为该档案的 `runtime`。
8. 使用自动 Java 启动一个已开放服务器，确认 Minecraft 正常进入；退出后检查
   游戏记录没有新的 Java 加载错误。
9. 中断一次 Java 下载或修复，再次修复，确认不会重新下载已校验的整套客户端。

## 回报内容

只提供启动器版本、发生时间、服务器名、界面简短错误和玩家主动生成的脱敏诊断包。
额外注明所选档案、界面显示的 Java 主版本以及使用“自动”还是“自定义”。不要提交
Microsoft 密码、浏览器地址栏、令牌、赫朝会话、私有下载链接或个人 Java 完整路径。

## 通过条件

- 每个客户端档案使用独立运行时，Java 21 与 Java 17 不互相覆盖。
- 新安装和修复会自动准备正确 Java，失败后可以继续。
- 不兼容自定义 Java 被拒绝，兼容选择按档案保存，恢复自动有效。
- 含空格或不可见格式字符的旧数据根目录可以构建并启动 Java 进程。
- 登录、设置、客户端、存档和下载缓存在覆盖升级后保持不变。
- 安装、校验、取消和 Java 选择失败均不冻结、不闪退。
