## 本轮修复

- 回收目录商品卡增加明确的“回收 >”操作，左键卡片直接打开既有服主回收容器；
- 首页“出售物品”改为“上架物品”，直接进入玩家市场定价上架流程，不再误入官方回收；
- 回收目录、出售页、玩家市场和个人设置返回首页时，不再先关闭本地 Screen；客户端只同步
  关闭容器状态并请求首页，等待新 Screen 原位替换，避免闪出游戏画面和鼠标回中；
- 首页从展示面板改为紧凑快捷菜单：常用分辨率使用 `3x2` 操作网格，按钮带物品图标，说明
  放入悬浮提示；中小窗口分别降级为双列或单列并保留分页；
- 回收卡片增加 `10` tick 防重复触发，价格和“回收 >”拥有独立文字宽度，避免互相覆盖。

## 行为边界

- 回收目录只负责打开既有 `hechaoeconomy:sell` 容器，物品接收、报价和入账仍由服务端裁决；
- 首页“上架物品”使用既有 `hechaoeconomy:ah sell` 流程，价格、手续费、白名单、库存和余额
  仍由服务端裁决；
- 返回首页不会在客户端提前 `setScreen(null)` 或调用本地 `closeContainer()`；
- 没有新增命令、权限、网络协议或经济数据写入；
- 没有部署或修改服务端插件。
