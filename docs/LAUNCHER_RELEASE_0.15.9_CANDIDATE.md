## 候选范围

1. 客户端更新继续按清单 SHA-256 复用当前档案和对象缓存，只下载本地缺失或内容变化的
   唯一对象；多个文件引用同一对象时只传输一次。
2. 安装器在进入网络阶段前验证对象缓存。有效缓存直接用于暂存，不再进入下载队列或
   产生 HTTP 请求。
3. 下载页将本地检查、增量下载、客户端准备、版本切换和 Java 准备分阶段显示。本地
   SHA-256 校验不再显示为下载速度。
4. 下载阶段的字节总量只统计真实缺失的唯一对象。档案完整大小仍用于本地检查、磁盘
   规划和完整性校验，不代表本次网络下载量。
5. 工业季 `1.0.11 -> 1.0.12` 的清单差异只有一个新增 JAR，真实新增对象为
   `27,450` 字节；其余 `4,456` 个共同文件保持不变，不需要重新下载整包。

## 发布边界

- 不覆盖 `0.15.8` 对象或标签；正式对象固定为
  `releases/launcher/0.15.9/Hechao-Launcher-Setup-0.15.9-win-x64.exe`。
- 最低支持版本保持 `0.12.3`，不扩大强制更新边界。
- 本次不修改工业季档案、OSS 客户端对象、API 合同、数据库、Minecraft 服务端、
  Velocity、服控代理或活动排期。
- 更新通道切换只允许重启 Launcher API；不得启动、停止或重启任何游戏服。

## 回滚

分发异常时恢复切换前 API 环境备份并只重启 Launcher API，或禁用启动器更新通道。
已经安装 `0.15.9` 的启动器不会自动降级；修复必须发布更高版本，不能覆盖本对象。
