# 赫朝启动器 API 0.38.1 后台会话恢复候选

> 候选日期：`2026-09-04`
> 当前状态：代码与自动化测试通过，待生产备份、原子部署和真实浏览器验收

## 问题与根因

管理员已经从启动器成功打开新的后台标签页时，先前停留在“需要管理员身份”的深层
链接不会感知同源 Cookie 已经建立，因此旧页会一直保持未登录画面。生产只读诊断确认
最近 24 小时的 6 张管理员票据全部成功兑换，6 个 Web 会话全部成功创建并由可信设备
完成 MFA；API `0.38.0`、PostgreSQL、Nginx 与 Cookie 设置均正常，问题位于旧标签页的
前端状态恢复，而不是票据、可信设备或商业街服务端。

## 修复范围

- 登录页在窗口重新获得焦点、页面从后台恢复可见或浏览器恢复页面时立即复核会话；
- 页面可见期间每 5 秒低频复核，覆盖并排窗口和焦点事件缺失的情况；
- 复核过程不切换加载页、不覆盖原错误信息，也不会并发发起重复检查；
- 会话恢复后保留原来的深层路由及 `server` 查询参数；
- 仍必须由启动器票据创建管理员会话，可信设备只跳过同一管理员的 MFA，不扩大认证
  权限边界。

## 部署与回滚

发布前备份数据库、API 环境文件、systemd 单元和当前发布链接。使用
`deploy/linux/install-release.sh` 原子切换，只重启 `hechao-launcher-api.service`；
就绪检查失败时脚本自动切回 `0.38.0-20260903T084151Z`。本版不新增数据库迁移，不操作
Publisher、Nginx、Velocity 或任何 Minecraft 服务端。
