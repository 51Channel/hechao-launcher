## 1. 变更

- 增加启动器本体自更新：
  - 登录后从已认证 API 检查最新与最低支持版本；
  - 支持可选更新和强制更新；
  - 从私有 OSS 短时 HTTPS 地址断点下载；
  - 复验长度与 SHA-256 后，由临时更新器等待主程序退出；
  - 静默覆盖安装并重新拉起；
  - 任一步骤失败均保留当前安装版本并记录本地错误。
- 已绑定 Minecraft 正版身份时，左下账号区域显示官方皮肤的头部与帽层：
  - 只接受 Mojang 官方会话服务和 `textures.minecraft.net`；
  - 只接受 64x32 或 64x64 PNG，并限制响应大小；
  - 使用 24 小时本地缓存，网络或图片异常时回退默认像素头像。
- 修复启动与退出进度的异步回调竞争，旧游戏进程的延迟事件不会覆盖新进程状态。

## 4. 发布与真实验收门槛

1. 上传到不可变私有对象
   `releases/launcher/0.13.0/Hechao-Launcher-Setup-0.13.0-win-x64.exe`。
2. 使用两次独立签名回读复验长度与 SHA-256，匿名读取必须为 `403`。
3. 部署 API `0.23.0`，但保持 `ServerControl__Enabled=false`。
4. 在 API 中发布 `0.13.0` 更新元数据，最低支持版本先保持 `0.12.3`。
5. 使用真实安装版 `0.12.3` 完成一次可选自更新，确认设置、会话和游戏目录保留。
6. 用真实绑定账号目视确认皮肤头像；断网时确认回退头像不影响登录与进服。
7. 完成内部小范围观察后，才决定是否提高最低支持版本。

## 5. 回滚

发布元数据可关闭或指回仍保留的 `0.12.3` 不可变对象。已安装 `0.13.0` 的玩家不会
自动降级；若需要程序级回滚，应基于 `launcher-v0.12.3` 发布一个更高版本号。回滚
不得删除 `%LocalAppData%\Hechao\GameData`、启动器设置、DPAPI 会话或客户端档案。
