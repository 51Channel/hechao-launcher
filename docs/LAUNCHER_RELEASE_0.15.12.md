## 变更内容

1. Windows DPAPI 会话改为同时保存访问令牌、刷新令牌和访问令牌过期时间；
2. 启动时优先复用仍有效的访问令牌，不再每次打开启动器都轮换刷新令牌；
3. `session.dat` 使用唯一临时文件原子替换，并保留加密的 `session.dat.bak`；
4. 断网、超时、取消和 API `5xx` 只进入可重试状态，不再清除玩家登录态；
5. 只有刷新接口明确返回 `401` 时才清除已失效会话；并发刷新或旧请求的二次 `401`
   不会删除另一个请求刚写入的新会话；
6. 启动恢复遇到临时网络故障时继续显示已登录账号，同时兼容旧版只保存刷新令牌的
   会话文件。

本版不改变 15 分钟访问令牌和 30 天刷新令牌的服务端安全策略，也不购买或引入 Windows
代码签名证书。安装包和主程序均保持 `NotSigned`，符合既有项目决策。
