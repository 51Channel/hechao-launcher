# API 0.33.0 经济服务候选

- 候选日期：2026-08-17
- 数据库迁移：`031_economy_ledger`
- 直接程序回滚目标：API `0.32.2-20260815T105349Z`
- 生产状态：尚未部署

## 功能

- 新增 `/v1/internal/economy` 内部 API，提供余额、转账、出售报价、出售确认和商品管理；
- 使用 PostgreSQL 双式账本、延迟平衡约束、序列化事务和幂等响应；
- 商品 ID 支持 `minecraft:` 与普通模组命名空间，例如 `create:brass_ingot`；
- 服务令牌只保存 SHA-256，并同时校验 `serverId` 白名单；
- 未配置令牌时经济端点返回 `503`，不会降级到 Essentials 本地余额；
- 商品修改记录操作者和修改前后 JSON 审计。

## 部署门禁

1. 先提交并推送候选源码，构建 `linux-x64` 自包含 API 制品并记录 SHA-256。
2. 备份当前 API、环境、systemd、Nginx 和 PostgreSQL，并验证数据库备份可读。
3. 使用新生成的外置明文令牌；API 环境只写 SHA-256，游戏服凭据文件只写明文令牌。
4. API 原子切换并自动执行迁移 `031`，本机和公网健康/就绪失败立即回滚程序链接。
5. 先把客户端档案 `1.0.12` 放入 Test；停服备份后同时替换 Bukkit 与 NeoForge 服务端 JAR。
6. 客户端和服务端屏幕协议必须同时为 `2`，不得只更新一端后开放玩家进入。

## 回滚

程序可回滚到 API `0.32.2`，但迁移 `031`、账本、审计、报价和幂等记录必须保留，禁止
数据库降级。游戏服回滚时暂停新交易并同时回退客户端和服务端屏幕；不得自动恢复
Essentials 本地经济。
