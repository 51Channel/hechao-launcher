# API 0.28.7 发布候选

## 修复范围

- 修复管理后台表单型抽屉被压缩到顶部的问题。打开的 Vue 抽屉本身使用三行 Grid，
  唯一子元素 `<form>` 此前只占据第一行，导致正文与页脚在约 `76px` 高度内重叠；
- 唯一表单现在跨越抽屉全部 Grid 行，表单内部继续使用固定页头、可滚动正文和固定页脚；
- 修复覆盖服务器新增/编辑和单服权限编辑等共享表单型抽屉，不改变目录、权限或服控 API。

## 候选验证

- TypeScript 类型检查通过；
- Vitest `8/8`；
- Playwright `18/18`，新增桌面和手机抽屉几何回归；
- API `289/289`、完整解决方案 .NET `695/695`；
- `1440x900` 下表单与抽屉等高，正文位于页头和页脚之间且高度大于 `300px`；
- `390x844` 下滚动到公告与开关区域后，保存操作仍固定可见；
- Release 全解决方案构建与 Vite 生产构建通过，生成的管理后台 CSS 已同步到 API 静态产物。

Linux 单文件制品和生产部署结果在正式发布前补齐。

## 发布与回滚

本版本没有数据库迁移，只发布 API `0.28.7`。部署只允许重启
`hechao-launcher-api.service`，不得操作 Minecraft、Velocity、Publisher、Nginx 或
两台 ServerControlAgent。

直接回滚目标为 API `0.28.6-20260806T150509Z`；readiness 或后置门禁失败时安装器必须
自动恢复该版本。
