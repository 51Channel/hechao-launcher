## 改版范围

`0.1.4` 的业务屏幕使用宽 `420 px` 深色面板、黄色竖线、`30 px` 高按钮和按钮说明，
在高 GUI 缩放下占据接近整屏宽度，信息层级也与玩家提供的原版快捷菜单参考不一致。

`0.1.5` 改为原版 Minecraft 风格的居中快捷菜单：

- 移除深色大面板、黄色竖线、副标题和按钮下方说明；
- 标题与 `20 px` 服务器授权提示按钮组成一个居中标题组；
- 普通宽度使用双列布局，双列总宽约为窗口宽度 `63%`，最大 `406 px`；
- 原版按钮高度固定为 `20 px`，列间距 `6 px`、行间距 `5 px`；
- 低宽度窗口自动切换单列，低高度窗口保留分页按钮和滚轮翻页；
- 六个现有入口、动作 ID、短期会话、白名单与服务端权限验证全部保持不变。

常见 `512 x 270` GUI 尺寸下，六个入口形成 `2 x 3` 网格，每个按钮宽 `158 px`，
双列总宽 `322 px`。该比例与用户提供的 Donut SMP 参考图一致，同时给背景游戏画面留出
足够空间。
