# API 0.28.1 发布候选

## 修复范围

- 服控概览不再把目录已删除且清理已完成的目标显示为日常受管服务器；
- 目录移出后仍在清理或仍有进行中操作时继续显示，避免管理员失去执行状态；
- 删除完成后自动切换到下一个可用目标，目标计数同步减少；
- 整合包重新创建目录并恢复心跳后，目标自动重新进入列表；
- 前端对旧概览响应执行相同的防御过滤，已删除状态不再保留重复删除按钮。

目标和操作审计记录仍保留在数据库，VPS 代理配置也不删除。修复只改变服控概览的日常
展示，不影响重新部署、外置备份、OSS 客户端或历史审计。

## 发布与回滚

本版本不新增数据库迁移，不升级 VPS 代理，只发布 API `0.28.1`。部署只允许重启
`hechao-launcher-api.service`，不得操作 Minecraft、Velocity、Publisher 或两台
ServerControlAgent。

生产已存在 `DeleteServerFiles` 操作记录，不能回滚到 `0.27.3`。本版本的直接安全回滚
目标是 API `0.28.0`；readiness 失败时安装器必须自动恢复该版本。
