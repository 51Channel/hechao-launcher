# 赫朝启动器主页操作菜单候选

- 候选日期：2026-08-08
- 基线正式版本：`0.15.1`
- 状态：源码候选，尚未发布
- 来源：用户提供的主页截图与本次实时验证

## 变更

1. 移除服务器主页下方的“客户端准备”和“运行配置”详情区，主页不再需要纵向滚动查看低频操作。
2. 在“启动游戏 / 安装客户端”主按钮右侧增加 IconPark 三点按钮。
3. 菜单只承载用户圈定的回滚、校验修复、删除、客户端设置、Java 自动和 Java 自定义。
4. Java、内存和游戏目录继续保留在首屏快捷设置中，目录操作不进入三点菜单；下载进度与取消任务继续由下载工作区承载。
5. 所有命令、禁用条件、危险操作确认和玩家设置保留逻辑保持不变。
