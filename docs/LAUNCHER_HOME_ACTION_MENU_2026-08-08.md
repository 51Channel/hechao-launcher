# 赫朝启动器主页操作菜单候选

- 候选日期：2026-08-08
- 基线正式版本：`0.15.1`
- 状态：源码候选，尚未发布
- 来源：用户提供的主页截图与本次实时验证

## 变更

1. 移除服务器主页下方的“客户端准备”和“运行配置”详情区，主页不再需要纵向滚动查看低频操作。
2. 在“启动游戏 / 安装客户端”主按钮右侧增加 IconPark 三点按钮。
3. 菜单只承载用户圈定的回滚、校验修复、删除、客户端设置、Java 自动和 Java 自定义。
4. Java、内存和游戏目录继续保留在首屏快捷设置中，目录操作不进入三点菜单；下载进度与取消任务继续由下载工作区承载。
5. 所有命令、禁用条件、危险操作确认和玩家设置保留逻辑保持不变。

## 2026-08-09 快捷设置后续候选

- 快捷设置改为无嵌套卡片的两行分组控制栏；Java、内存和当前档案目录使用 IconPark
  图标、明确标签和细分隔线组织，最小窗口仍为目录保留可读宽度。
- 主页目录从全局 `ClientDirectory` 改为所选档案的
  `SelectedProfileGameDirectory`，即真实
  `instances\<profile-id>\.minecraft`；文件夹按钮使用独立命令打开同一路径。
- 主页移除全局数据根目录更改按钮。该能力仍完整保留在设置页，避免把启动器存储根目录
  与当前 Minecraft 游戏目录混为一谈。
- 该后续候选仍未修改版本号、安装包、OSS 或生产更新通道。
