## 上线内容

- 启动器与论坛共用账号名、邮箱、显示名称和密码。
- 新账号统一经过论坛邮箱验证码注册，公开 API 不再允许绕过论坛直接注册。
- 论坛支持赫朝账号名或邮箱登录；修改昵称、修改密码和找回密码会同步到账号 API。
- Microsoft / Minecraft 正版绑定继续独立处理，只验证游戏所有权，不保存 Microsoft 密码。
- 论坛资料、角色、封禁、帖子和通知仍保存在论坛；游戏权限继续由 LuckPerms 管理。
- 旧论坛账号完整迁入 PostgreSQL，首次登录兼容旧 scrypt 密码并自动升级密码格式。
- 论坛会话增加版本号，改密与找回密码会撤销其他旧会话。

## 回滚
