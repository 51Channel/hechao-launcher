## 修复范围

`0.1.3` 只提供 `/hechaomenu economy` 和 `/heco menu` 指令，没有向 Minecraft 暂停
菜单注册入口。因此用户看到“模组”整行按钮属于旧版本的预期实现缺口，不是渲染失败。

`0.1.4` 在真正的 `PauseScreen` 初始化后定位原生 `fml.menu.mods` 按钮，将该行拆为
左侧“模组”和右侧“天域远征”两个 `98 px` 按钮，并保留原生 `8 px` 间距。不增加
纵向菜单行，避免低高度窗口溢出。

点击新按钮只向服务端发送固定命令 `hechaomenu economy`。客户端不直接打开业务屏幕，
短期会话、动作白名单和权限检查继续由服务端控制。单人暂停菜单、未连接服务器和未找到
原生模组按钮时保持故障关闭。
