## 下载优化

- 客户端对象由串行改为最多 16 路受控并行，按 SHA-256 去重，同一内容只下载一次。
- 游戏对象下载绕过 Windows 系统代理；登录、目录、账号和普通 API 仍使用系统网络设置。
- Range 断点续传、逐对象 SHA-256、签名清单、暂存目录和原子版本切换全部保留。
- 临时取消、断流、429 和 5xx 最多重试 5 次，使用指数退避、随机抖动并尊重 `Retry-After`。
- 下载中心显示实时速度，进度聚合保持单调且不跨线程写界面。
- API `0.11.1` 为已授权对象设置独立令牌桶：容量 `192`、每秒补充 `80`；登录每 IP 每分钟 `10` 和全局每 IP 每分钟 `6000` 保持不变。
