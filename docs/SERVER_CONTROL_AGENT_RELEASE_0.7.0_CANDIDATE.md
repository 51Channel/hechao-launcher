# ServerControlAgent 0.7.0 独立部署槽候选

> 日期：2026-08-15
>
> 目标：仅升级 owl5；owl9 保持 `0.4.0`。
>
> 状态：候选已验证，尚未发布生产。

## 变更

- `CreateDeploymentSlot` 增加 API 批准的端口和槽类型。
- 支持 `activity-*`、`survival-*`、`pvp-*`、`minigame-*`，类型与 ID 前缀不一致时拒绝。
- 动态槽使用独立端口和空冲突组，`server.properties` 写入该槽端口，不再复制 `25568`。
- 创建前同时检查静态目标、已持久化动态目标和本机真实 TCP 监听；冲突时不创建文件。
- 独立目录、计划任务、固定文件快照、部署标记和失败自动回滚语义保持不变。
- 旧版已经持久化的共享活动替换槽仍可加载；只有显式迁移或新建的独立槽要求空冲突组和
  `25600-25611` 独立端口。

## 候选验证

- ServerControlAgent：`71/71`；完整 .NET 解决方案：`780/780`。
- 覆盖四类槽、独立端口、空冲突组、类型前缀错配、端口冲突不落盘、成功重放与失败回滚。
- 本版本只重启服控代理，不自动操作 Minecraft 进程。

## 发布与回滚

1. 备份代理 EXE、配置、动态槽状态、任务安装器和目标服务端配置。
2. 停止服控代理任务；保持 Minecraft 当前运行状态不变。
3. 迁移既有动态槽端口和状态后部署 `0.7.0`，再恢复代理任务。
4. 验证固定活动 PID、启动时间和 `25568` 监听未变化；既有停止槽继续保持停止。
5. 失败时恢复代理、状态和服务端配置备份，不启动任何服务端。
