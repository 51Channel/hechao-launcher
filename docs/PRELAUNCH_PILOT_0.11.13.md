# 启动器 0.11.13 小范围测试手册

> 范围：管理员本机与 2 至 3 名内部玩家
>
> 目标：验证隐私受限运行遥测，并回归登录、安装、修复、回滚、诊断上传与真实游戏启动

## 安装前

- 只使用管理员提供的私有短时链接。
- 文件名必须为 `Hechao-Launcher-Setup-0.11.13-win-x64.exe`。
- 文件大小必须为 `61,868,113` 字节。
- SHA-256 必须为
  `E6BF44D9971CEF6D874368E9912158BC60B88A886C652318E94F9D4BE0FFCFE7`。
- 可以直接覆盖 `0.11.12`，不要删除客户端、Java 或游戏数据目录。
- 安装包未做 Authenticode 签名；只接受上述文件名、大小和 SHA-256。

## 必测流程

1. 覆盖安装后确认版本显示 `0.11.13`，赫朝账号、Minecraft 绑定、设置、
   已安装档案、受管 Java 与玩家存档保留。
2. 登录后完成一次基础档案检查、一次修复和一次游戏启动；启动失败时
   启动器必须保持运行并显示可诊断错误。
3. 断网完成一次允许离线排队的操作，恢复网络后继续使用，界面不得卡死或闪退。
4. 以自动 Java 分别启动基础、NeoForge 活动和 PVP Fabric 档案；再为一个档案
   选择正确主版本的自定义 Java，成功后切回自动 Java。
5. 中断一个客户端下载后继续，确认从已有分片续传；修改受管文件后执行修复。
6. 在存在有效 `.previous` 时回滚客户端版本，确认当前存档、截图、设置和
   服务器列表保留；Minecraft 运行时回滚按钮必须禁用。
7. 从设置页生成脱敏诊断包，先取消上传，再确认上传；界面应保持响应，
   完成后显示诊断编号与到期时间。
8. 在上传前移动或修改本地 ZIP，确认启动器拒绝上传且不会退出。
9. 管理员登记 MFA 后核对“运行数据”页面中的启动器版本、事件结果和失败分类，
   并下载诊断编号、核对下载审计。

## 隐私核对

- 遥测不得包含赫朝账号、Minecraft UUID、显示名、文件路径、日志正文、
  会话令牌、Microsoft 凭据或私有下载链接。
- 诊断上传必须由玩家在确认框中主动同意，不得后台自动上传。
- ZIP 不得包含世界存档、账号密码、浏览器地址、赫朝会话、Minecraft
  令牌、服务器凭据或私有下载链接。
- 玩家本地诊断包与服务端副本分别受本地保留上限和 14 天到期策略约束。

## 通过条件

- 登录失败、取消登录、安装失败、遥测失败和上传失败均不会退出启动器。
- 全新安装与 `0.11.12` 覆盖升级不清除账号、设置、客户端或玩家数据。
- 自动 Java、自定义 Java、修复和回滚至少各完成一次真实操作。
- 后台聚合只出现固定分类和版本数据，不出现玩家身份或本机路径。
- 管理员 MFA 下载成功且审计记录完整后，诊断上传项才可标记为生产验收完成。
- 本轮无阻断问题后，才能进入 5 人灰度；5 人通过后再进入 20 人灰度。
