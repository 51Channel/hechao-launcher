# 天域远征工业季玩家市场 0.2.0 候选

- 候选日期：2026-08-18
- 状态：本地候选，未部署
- API：`0.35.0`
- 服务端插件：`HechaoEconomy-0.2.0.jar`
- 客户端模组：`HechaoEconomyScreen-NeoForge-1.21.1-0.2.0.jar`
- 数据库迁移：`034_economy_player_market`

## 功能范围

玩家入口为 `/ah`，客户端首页增加“玩家市场”。市场包含四个长期入口：玩家市场、上架
物品、我的挂单和待领取。浏览列表点击商品进入购买确认；我的挂单点击商品进入下架确认；
待领取点击商品完成领取。

上架使用单槽放入式界面，保留原生拖放和 Shift 点击。玩家填写整组物品总价，价格最低
`1.00` 且最多两位小数。候选规则为 `1%` 上架费、最低 `1.00` 上架费、`3%` 成交税、
`24h` 有效期和每人最多 `5` 个活动挂单。上架费不因下架退回。

购买、下架和到期物品进入待领取。服务端在领取前检查背包容量，领取期间出现背包竞争或
网络结果不明时写入隔离记录，不把物品掉落到世界。市场数据按 `serverId` 隔离，避免不同
整合包之间交付不兼容物品。

## 模糊搜索

玩家市场、我的挂单和待领取顶部均有搜索框，回收目录沿用同一套搜索协议：

- 支持中文本地化显示名、完整或部分物品 ID、命名空间；
- 玩家市场和我的挂单额外支持卖家名；
- 支持连续包含和有序字符模糊匹配，例如 `mci` 可匹配
  `minecraft:iron_ingot`；
- 客户端将中文命中的物品注册 ID 安全编码后交给服务端，服务端只在当前玩家已打开的菜单
  会话内过滤；
- 输入防抖为 `8 tick`，约 `0.4` 秒，清空输入会恢复完整列表；
- 回收目录按完整商品会话过滤后再分页，不再局限当前服务端批次。

搜索命令是客户端与插件之间的内部协议，不作为玩家手工输入文档：

```text
hechaoeconomy:ah search <base64url-query|-> <item-ids|->
hechaoeconomy:shop search <base64url-query|-> <item-ids|->
```

服务端限制查询长度、过滤物品 ID 格式并限制客户端映射 ID 数量，搜索不会触发余额修改、
物品发放或权限提升。

## 一致性边界

API 通过幂等键保护上架、购买、下架和领取。购买在一个 PostgreSQL 事务中完成买家扣款、
卖家到账、税费转入系统费用账户、挂单状态更新和待领取创建；重复请求返回原结果，不能
重复扣款或复制物品。到期挂单在市场读取、个人挂单读取和待领取读取前统一结算。

本候选只接受 `SellItemPolicy` 认可的普通物品，以 `itemId + quantity` 托管。以下能力明确
未实现：

- 命名、附魔、Lore、耐久、药水、地图、烟花和其他复杂 Data Components/NBT；
- 箱子、潜影盒、Bundle 或任何携带内部库存的物品；
- 带能量、流体、升级、频率或能力数据的模组物品；
- 按 LuckPerms 等级将挂单上限提高到 `10/15`；
- 玩家市场成交历史、趋势图和排行榜；
- 真正由服务器出售物品并回收金币的 `/shop`。
