# 启动器 0.11.11 小范围测试手册

> 范围：管理员本机与 2 至 3 名内部玩家
>
> 目标：验证玩家主动回滚，并回归安装、修复、Java 与真实游戏启动

## 安装前

- 只使用管理员提供的私有短时链接。
- 文件名必须为 `Hechao-Launcher-Setup-0.11.11-win-x64.exe`。
- 文件大小必须为 `61,823,943` 字节。
- SHA-256 必须为
  `F6687C4CBB53BEFB3DC3D8B84FFBDF0AEC589DF69D710EE4F5DF43EFD47CB894`。
- 可以直接覆盖 `0.11.10`，不要删除客户端、Java 或游戏数据目录。

## 回滚准备

回滚按钮只有在对应档案已经至少成功切换过一次、启动器保留了有效
`.previous`，并且 Minecraft 已退出时才会启用。没有上一版时显示禁用属于正常
状态；不得手工伪造 `.previous`。

为避免用正式世界做破坏性试验，管理员应发布一个只改动无状态测试标记的小版本，
或使用专门灰度档案完成双向切换。回滚前后都不要删除玩家存档。

## 必测流程

1. 覆盖安装后确认版本显示 `0.11.11`，赫朝账号、Minecraft 绑定、内存和档案保留。
2. 没有上一版的档案确认“回滚版本”禁用且提示原因正确。
3. 安装灰度档案的新版本，确认当前版就绪且回滚按钮显示上一版版本号。
4. 在 `.minecraft` 中创建测试存档、截图和设置变更，退出 Minecraft 后确认回滚。
5. 回滚完成后确认受管文件来自上一版，但测试存档、截图、设置和服务器列表仍在。
6. 确认主按钮显示“更新客户端”；再次更新后，原回滚版本仍可作为上一版。
7. Minecraft 运行时确认回滚按钮禁用；退出后恢复可用。
8. 同时打开第二个启动器进行修复，确认另一个窗口不能并发回滚同一档案。
9. 使用自动 Java 启动回滚版本；若档案 Java 主版本不同，确认启动器自动补齐。
10. 回归基础、活动 NeoForge 和 PVP Fabric 的安装、修复与真实启动。

## 回报内容

提供启动器版本、档案 ID、回滚前后档案版本、Windows 缩放比例、发生时间和玩家
主动生成的脱敏诊断包。不要发送 Microsoft 密码、浏览器地址栏、令牌、赫朝会话
或私有下载链接。

## 通过条件

- 回滚仅在上一版有效、无安装任务且 Minecraft 未运行时启用。
- 受管客户端切换到上一版，玩家数据保持当前状态。
- 中途失败不会把当前版或上一版同时删除。
- 回滚后 Java 可用，或者明确提示通过修复继续。
- 覆盖升级不清除账号、设置、客户端、存档或下载缓存。
- 启动失败时启动器保持运行并提供可诊断错误。
