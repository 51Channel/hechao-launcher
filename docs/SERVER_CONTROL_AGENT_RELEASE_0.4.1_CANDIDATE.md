# ServerControlAgent 0.4.1 发布候选

## 范围

- 通过 Windows `GlobalMemoryStatusEx` 读取 VPS 真实物理内存并随心跳上报；读取失败时
  上报空值，不猜测容量。
- 仅对启用整合包部署的固定活动槽，以向下对齐 `256 MiB` 的 VPS 物理容量替代旧的
  `maximumAllowedMemoryMiB=8192` 人工限制。
- 其他服务端继续使用各自现有内存配置；本版本不会改写其 JVM 参数。
- 活动槽仍保留 `64 GiB` 技术边界、结构化命令、停服检查、目录访问门闩、原子切换和
  失败回滚。

## 验证

- ServerControlAgent `56/56`；
- 完整解决方案 `.NET 680/680`；
- `32 GiB`、非 `256 MiB` 对齐容量、超过 `64 GiB` 容量、非部署目标和容量读取失败
  均有确定性单元测试。

## 部署边界

- 只升级 owl5；owl9 没有整合包部署目标，本轮保持 `0.4.0`；
- 安装前后记录全部 Java PID、启动时间和路径，集合必须不变；
- 只停止并恢复服控代理计划任务，不操作任何 Minecraft 或 Velocity 计划任务；
- 新心跳必须显示 `0.4.1`、真实 VPS 总内存和活动槽建议区间，否则回滚代理。
