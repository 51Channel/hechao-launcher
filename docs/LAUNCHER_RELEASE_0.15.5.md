## 变更内容

1. 删除侧栏底部社区声明，只保留账户卡作为底部锚点，减少无业务价值的占位内容。
2. 账户卡、服务器目录和快捷设置统一 `14px` 底边距；服务器目录左右两侧留白也统一
   为 `14px`，使左侧目录与右侧主视区在高窗口下保持共同边线。
3. 服务器目录改为占满剩余业务高度并在内部滚动；当前服务器、公告/活动和快捷设置
   使用带上下限的弹性比例，不再依赖独立底部填充行。
4. 当前服务器详情保持垂直居中，主操作紧跟详情，并保留稳定最小高度，避免按钮底边
   在最小窗口或高 DPI 下被裁切。
5. 服务器目录、客户端下载、自更新、账号、活动月历、快捷设置和游戏启动状态机均未
   改动，没有增加虚构服务器或运营数据。
