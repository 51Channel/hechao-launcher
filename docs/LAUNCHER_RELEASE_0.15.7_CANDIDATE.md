# 赫朝启动器 0.15.7 候选发布记录

- 候选日期：2026-08-10
- 上一正式版本：`0.15.6`
- 统一源码基线：`0c475f3`
- 候选分支：`codex/launcher-0.15.7-activity-sync`
- 正式状态：已于 2026-08-10 发布；正式记录见 [`LAUNCHER_RELEASE_0.15.7.md`](LAUNCHER_RELEASE_0.15.7.md)。

## 候选范围

1. 删除左下账户卡右侧与“账户”导航重复的独立账号操作按钮。
2. 同时删除按钮预留列和标题右侧空白，让账号名称与身份信息使用完整可用宽度。
3. “账户”导航、账户页登录与退出、设置页账号操作及管理员后台入口保持不变。
4. 打开 Launcher 活动页时立即刷新活动目录；停留期间每 30 秒同步一次，离开页面后
   停止轮询。后台刷新失败保留最后一次安全数据，不再反复弹出错误提示。
5. 跨午夜企划严格按 `[开始, 结束)` 映射到月历；结束时间恰好为 `00:00` 时，不把结束日
   错算为活动占用日。
6. Launcher 后台、官网后台、Launcher 活动页和官网公开日历继续读取 API `0.30.0` 的
   同一组企划；官网只显示公开时间，活动客户端仍只能在 Launcher 内下载。

## 发布边界

- 当前正式版本为 `0.15.7`；不可变 OSS 对象和生产更新元数据均已切换。
- Launcher API 保持生产 `0.30.0`，本候选不修改 PostgreSQL、迁移、企划记录或活动槽。
- 管理后台仍要求由同一台电脑上的启动器签发一次性管理员票据，票据来源网络地址校验
  不变；不能通过直接收藏 `/admin` 深层地址绕过登录。
- 不修改服务器目录、客户端档案、游戏启动状态机或 Minecraft 数据。
- 不启动、停止或重启 Minecraft、Velocity、服控代理、API 或 Publisher。

## 回滚

若分发异常，可恢复 API 环境备份并只重启 Launcher API；已经安装 `0.15.7` 的客户端
不会自动降级。界面或同步策略修复必须发布更高版本，不得覆盖 `0.15.7`、既有 OSS
对象或 Git 标签。
