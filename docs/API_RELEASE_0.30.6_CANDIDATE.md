# API 0.30.6 发布候选

> 历史状态：本候选已于 2026-08-14 作为 `0.30.6-20260814T133415Z` 正式发布。
> 正式记录见 [`API_RELEASE_0.30.6.md`](API_RELEASE_0.30.6.md)。

- 候选版本：`0.30.6`
- 数据库迁移：无，保持 `028`
- 直接回滚目标：`0.30.5-20260814T121420Z`

## 修复范围

- 活动企划接口新增 `unmanagedSchedules`，只查询 `velocity_target=activity`、已经设置
  开放或结束时间、但 `activity_plan_status IS NULL` 的旧服务器目录排期；
- 管理后台将这类记录以独立告警清单和蓝色虚线日历事件显示，避免启动器有活动而后台
  月历完全空白；
- 点击旧排期可查看开放/结束时间、客户端档案、整合包绑定和明确缺失项，并可前往
  服务器目录或整合包导入页面；
- 旧排期保持只读，不计入正式企划统计，不能拖动、发布、部署，也不会自动修改数据库
  或提交任何 Minecraft 启停命令；
- `赫朝商务追杀` 当前只有北京时间 2026-08-15 17:00 的开放时间，缺少结束时间、
  正式企划状态和整合包企划绑定，因此本版本只负责如实显示，不猜测结束时间或强制转换。

## 发布边界

只发布 API 与其内嵌管理后台。生产切换前必须确认无正在执行的整合包、服控或数据库
任务，完成 PostgreSQL custom-format 备份以及当前 API、环境、systemd、Nginx 备份。
部署只允许重启 `hechao-launcher-api.service`，不得重启 Publisher、Nginx、Velocity、
服控代理或任何 Minecraft 服务端。

安装器就绪检查失败时必须自动恢复 `0.30.5-20260814T121420Z`。部署后除健康、就绪、
回环监听、旧站点、日志和任务队列外，还要从生产活动企划接口确认 `activity` 出现在
`unmanagedSchedules`、正式 `plans` 仍为 `0`，并确认后台静态产物包含只读提示和缺失项。
