1. 完成玩家主动回滚，并发布新的启动器候选。
2. 完成诊断上传的隐私与服务端闭环。
3. 完成管理后台目录高级规则、玩家权限和客户端发布管理。
4. 扩展状态指标、告警、异地备份和恢复演练。
5. 登记管理员 MFA，使用四级真实账号完成 `monitor` 灰度。
6. 验证 NPC、`/hub`、断线重连和 API 故障，切换 Velocity `enforce`。
7. 启用目录强制登录，完成 5 人和 20 人灰度及真实回滚。
8. 一个观察周期无阻断故障后，形成正式发布公告和最终审计记录。
