# 赫朝启动器主页三栏改版

- 候选日期：2026-08-08
- 基线正式版本：`0.15.0`
- 正式版本：`0.15.1`
- 状态：已完成私有 OSS、生产更新通道和真实登录态更新链验收
- 来源：用户提供的主页参考图、现有 WPF 业务绑定与当前任务实时验证

## 改版范围

1. 主导航由窄图标栏改为图标加文字的宽导航，保留服务器、下载、活动、账户和设置五个真实工作区。
2. 服务器目录继续使用权威目录返回的名称、状态、版本、真实人数和活动排期，不增加“添加服务器”等管理员入口。
3. 当前服务器区域改为左侧品牌横幅、右侧信息与主操作；主按钮继续绑定 `PrimaryActionCommand`，安装、更新、登录、绑定和进入服务器的原状态机不变。
4. 增加主页公告投影，只显示当前玩家可见服务器的非空 `Announcement`，空数据时显示“暂无服务器公告”。
5. 增加近期活动投影，只显示仍在进行或未来的前三个真实排期；过期与未排期活动不进入近期列表，完整信息继续由活动月历承载。
6. Java、内存和游戏目录变为首屏快捷设置；完整客户端准备进度、修复、回滚、删除、自定义 Java 和目录操作继续保留在下方滚动区域。

## 产品与设计约束

- 新增仓库级 `PRODUCT.md`，记录启动器唯一换服入口、真实目录权威、玩家与管理员职责边界。
- 新增仓库级 `DESIGN.md`，固定三栏主页、赫朝红、IconPark、苹方优先字体、最大 `8` 像素圆角和禁止伪造数据等规则。
- 参考图只用于布局和信息层级；没有照搬其中的假公告、假人数、延迟、收藏或服务器管理入口。
