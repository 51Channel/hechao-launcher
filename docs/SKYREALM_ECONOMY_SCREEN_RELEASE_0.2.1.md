## 功能变更

个人账户页从单一金币数字改为账户信息区：显示可用余额、冻结余额和总资产，并保留玩家
市场、我的挂单、待领取三个快捷入口。我的队伍命令改为明确发送
`skyrealmcore:team list`，结果页支持连续接收队伍、队长和成员多行响应；无关聊天不会
被页面接管。

个人设置页不再显示原版容器，而是由 Screen 接管为统一的天域设置界面，保留服务端三个
受控槽位的开关状态与点击裁决。出售物品页根据容器周围可用空间自适应标题区、底部按钮
和窄窗口侧边按钮，避免按钮与物品槽重叠。

客户端只负责渲染和发送受限命令，不修改余额、价格、库存、权限或队伍状态。
