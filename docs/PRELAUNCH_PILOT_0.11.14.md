# 启动器 0.11.14 小范围测试手册

> 范围：管理员本机与 2 至 3 名内部玩家
>
> 目标：验证启动检查开关，并回归登录、安装、修复、回滚、诊断上传与真实游戏启动

## 安装前

- 只使用管理员提供的私有短时链接。
- 文件名必须为 `Hechao-Launcher-Setup-0.11.14-win-x64.exe`。
- 文件大小必须为 `61,866,744` 字节。
- SHA-256 必须为
  `82542FEBDD826AF4C40D8E0AFCD65990BE54A748734829FA7EC46214A27E5EDB`。
- 可以直接覆盖 `0.11.13`，不要删除客户端、Java 或游戏数据目录。
- 安装包未做 Authenticode 签名；只接受上述文件名、大小和 SHA-256。

## 必测流程

1. 覆盖安装后确认版本显示 `0.11.14`，赫朝账号、Minecraft 绑定、设置、
   已安装档案、受管 Java 与玩家存档保留。
2. 保持“启动时检查客户端更新”开启，重启启动器，确认所选档案自动进入检查并显示
   “客户端已就绪”“发现新版本”或“尚未安装”。
3. 关闭该开关并重启启动器，确认先显示“启动检查已关闭”，主按钮显示
   “检查客户端”，且界面保持可操作。
4. 在关闭状态点击主按钮，确认启动器先完成客户端检查，再根据结果安装、更新、
   绑定正版身份或进入服务器，不能直接绕过检查。
5. 再次关闭并重启，然后打开该开关，确认当前档案立即检查且启动器不闪退。
6. 分别回归一次安装或修复、一次主动回滚和一次真实游戏启动；失败时启动器必须
   保持运行并显示可重试状态。
7. 中断一个下载后继续，确认从已有分片续传；以自动 Java 启动至少一个档案。
8. 生成脱敏诊断包并主动确认上传；取消、网络失败和文件被修改时都不得退出启动器。
9. 管理员登记 MFA 后核对“运行数据”页面中的启动器版本、事件结果和失败分类，
   并下载诊断编号、核对下载审计。

## 通过条件

- 开关只影响启动时的自动扫描，不影响进服前强制检查、签名清单、哈希校验或 Java。
- 登录失败、取消登录、检查失败、安装失败和上传失败均不会退出启动器。
- 全新安装与 `0.11.13` 覆盖升级不清除账号、设置、客户端或玩家数据。
- 自动 Java、修复、回滚和真实启动至少各完成一次。
- 本轮无阻断问题后才能进入 5 人灰度；5 人通过后再进入 20 人灰度。
