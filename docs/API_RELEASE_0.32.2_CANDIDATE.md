# API 0.32.2 目录档案完整性修复候选

- 候选日期：2026-08-15
- 数据库迁移：无
- 直接回滚目标：API `0.32.1-20260815T071021Z`

## 问题

生产目录中存在已设为可见、但当前玩家发布通道没有可用客户端版本的服务器。API 仍会
返回该服务器，而 `clientProfiles` 不会包含对应档案。启动器按完整性规则拒绝整份目录，
回退到上次成功缓存并显示“目录服务暂时不可用”。

本次生产实例为 `activity-survival`：普通玩家使用的 `Production` 通道没有发布版本，
但 `activity` 的赫朝商务追杀正式档案完整可用。一条未发布记录因此连带阻断了商务追杀。

## 修复

- API 在完成玩家通道和灰度解析后，只返回能够同时下发对应客户端档案的服务器；
- 未发布服务器继续保留在后台和数据库中，不会被删除、改写或误发布；
- 已具备正式档案的赫朝商务追杀继续正常出现在实时目录；
- 增加回归测试，保证缺少档案的服务器只过滤自身，不再拖垮其他目录记录。
