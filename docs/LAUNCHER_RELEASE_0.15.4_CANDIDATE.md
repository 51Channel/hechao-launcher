## 发布边界

- 不改变服务器目录数据、客户端档案、服务器开放状态、官网业务内容或后台数据。
- 不启动、停止或重启 Minecraft、Velocity、服控代理或常驻 Publisher Agent。
- 生产切换只新增私有 OSS 不可变安装包，并更新 Launcher API 的启动器版本元数据；
  切换前备份 API 环境文件，任一验收失败立即恢复。
- 最低支持版本保持 `0.12.3`，不扩大强制更新边界。

## 回滚

发布失败时保持 `LatestVersion=0.15.3`。切换后若发现分发异常，恢复本次 API 环境备份
并只重启 Launcher API，或关闭 `LauncherUpdates__Enabled`。已经安装 `0.15.4` 的客户端
不会自动降级；后续修复必须使用更高版本，禁止覆盖任何已上传对象或既有标签。
