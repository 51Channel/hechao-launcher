# 赫朝启动器 0.15.2 候选发布记录

- 候选日期：2026-08-09
- 上一正式版本：`0.15.1`
- 功能来源提交：`c6b211f`、`d689331`
- 目标正式标签：`launcher-v0.15.2`

## 发布范围

1. 移除主页下方重复的客户端详情区，只把回滚、校验修复、删除、客户端设置与两种
   Java 模式收进主操作右侧三点菜单。
2. 快捷设置改为两行分组控制栏，Java、运行内存和游戏目录使用 IconPark 图标、细分隔线
   与稳定响应式宽度。
3. 主页游戏目录改为当前档案真实
   `GameData\instances\<profile-id>\.minecraft`；未选择服务器时显示明确空状态并禁用
   目录按钮，全局 `GameData` 修改入口继续只保留在设置页。
4. 官网同源活动月历、客户端下载、自更新、账号、目录过滤和游戏启动状态机保持不变。

## 发布边界

- 不改变活动目录、客户端档案、服务器开放状态、官网内容或后台业务数据。
- 不启动、停止或重启 Minecraft、Velocity、服控代理或常驻 Publisher Agent。
- 生产切换只新增私有 OSS 不可变安装包并更新 Launcher API 的启动器版本元数据；切换前
  备份 API 环境文件，任一验收失败立即恢复。
- 最低支持版本保持 `0.12.3`，不扩大强制更新边界。

## 回滚

发布失败时保持 `LatestVersion=0.15.1`。切换后若发现分发异常，恢复 API 环境备份或
关闭 `LauncherUpdates__Enabled`，再只重启 Launcher API。已经安装 `0.15.2` 的客户端
不会自动降级；代码修复继续使用更高版本，禁止覆盖任何已上传对象或既有标签。
