# Velocity Authorizer 0.5.0 动态后端候选

> 日期：2026-08-15
>
> 状态：候选已验证，尚未发布生产。

## 变更

- 授权响应新增可选 `backendHost` 与 `backendPort`。
- 首次授权到未注册动态槽时，插件使用批准地址注册 `ServerInfo` 后完成路由，不需要修改 `velocity.toml`。
- 固定服务器继续使用现有静态注册，不改变大厅隔离、一次性授权或客户端兼容门禁。

## 安全边界

- 动态地址只接受 `127.0.0.1` 或 `::1`，端口必须在有效范围内。
- 地址字段不完整、外部地址、非法目标名或已注册地址不一致时故障关闭。
- API 只为状态为 `Ready` 的数据库槽返回动态地址；拒绝响应不携带后端地址。

## 候选验证

- Gradle 测试：`31/31` 通过。
- 覆盖数字解析、回环地址、动态注册、外部地址拒绝和既有首次故障关闭行为。
- 正式部署前必须确认 Velocity 无在线玩家；部署需要管理员单独重启 Velocity。
