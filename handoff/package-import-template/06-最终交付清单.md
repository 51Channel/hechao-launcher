# 最终交付清单

## 制品

- [ ] 业务 ZIP 根级布局为 `hechao-pack.json + client + server + 可选 shared`
- [ ] 不含 `.example`、占位符、外层包装目录或嵌套 `.minecraft`
- [ ] 已生成同名 `.sha256` 和 `.report.json`
- [ ] 从最终 ZIP 全新解压后的文件集合与报告一致
- [ ] 没有秘密、账号缓存、日志、符号链接或重解析点

## 客户端

- [ ] `hechao-profile.json` 与版本目录、版本 JSON/JAR 完全一致
- [ ] assets、libraries、mods 和配置完整闭合
- [ ] Java 运行时未打包，由启动器管理
- [ ] 全新隔离安装和启动通过
- [ ] 错误档案能够清楚失败

## 服务端

- [ ] `server.properties`、`eula.txt`、`user_jvm_args.txt`、`start.bat` 存在
- [ ] `start.bat` 包含受管标记并引用唯一 JVM 参数文件
- [ ] `serverCore` 已声明，并与 `start.bat` 实际启动核心及组件计划一致
- [ ] 精确加载器、mods/plugins/config 与组件计划一致
- [ ] `forwarding.secret` 未打包，非秘密 forwarding 配置已核对
- [ ] 专用服务端启动、端口、授权、保存和安全停服通过
- [ ] 地图来源、玩家数据清理、备份和恢复已验证

## 双端

- [ ] 共同 JAR 来自同一次构建，客户端和服务端 SHA-256 一致
- [ ] 客户端专用和服务端专用依赖已分开
- [ ] 原生模组加载器中没有 Bukkit 插件
- [ ] 许可证允许当前分发方式
- [ ] 自动测试和目标人数灰度已记录
