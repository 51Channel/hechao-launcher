# 开发与上线验收清单

## A. 开发准备

- [ ] 已阅读包内 `AGENTS.md`、活动通道总规范和新服务端基础组件规范
- [ ] 已找到实际活动源码仓库，Git 状态已核对
- [ ] 新活动需求单已填写，不含凭据
- [ ] 已确定新档案或原档案升版
- [ ] Minecraft、加载器、Java 和依赖兼容性已真实核验
- [ ] 组件计划已填写，平台单例、大厅专用、主机级和后端组件分层正确
- [ ] forwarding 与指标实现精确兼容；无兼容实现时已阻塞生产
- [ ] `activityId/serverId/controlTargetId/profileId` 稳定且不冲突
- [ ] `velocityTarget=activity`
- [ ] `port=25568`、`conflictGroup=owl5-activity-slot`
- [ ] 地图授权、备份和回滚目标明确
- [ ] 本次生产授权边界明确

## B. 代码与协议

- [ ] common/client/server 职责分离
- [ ] 专用服务端不会加载客户端类
- [ ] C2S 只表达意图
- [ ] 服务端验证身份、阶段、角色、存活、距离、频率和序号
- [ ] 网络包有协议版本和长度上限
- [ ] 重复、延迟和旧回合包被安全拒绝
- [ ] 玩家名称未被用作持久身份，使用转发 UUID
- [ ] 后台任务有界、可取消、可超时
- [ ] 世界 API 只在服务端线程调用
- [ ] 物资/结构按 tick 预算生成
- [ ] 没有通过改变半径、人数或规则掩盖性能问题

## C. 既有故障回归

- [ ] 死亡观察者不能救人、得分或使用活人技能
- [ ] nametag/TAB/计分板/发光只有一个所有者
- [ ] 角色数量覆盖 `0/1/2/6/7/8/20`
- [ ] 集合传送不会把玩家放进同一碰撞箱
- [ ] UI 连点和重复网络包不能突破次数限制
- [ ] 断线重连不复制角色、物资、实体或分数
- [ ] 换图和新回合取消旧生成队列
- [ ] 没有新增 `/hub`、大厅 NPC 或自动换服

## D. 本地验收

- [ ] Gradle/构建测试全部通过
- [ ] 无图形专用服务端启动通过
- [ ] 一个管理员完整启停和重连
- [ ] 两客户端同步通过
- [ ] 错误/缺失客户端得到明确拒绝
- [ ] 7 人角色边界通过
- [ ] 20 人预检无阻断错误
- [ ] 持续 TPS 不低于 `19.5`
- [ ] MSPT 95 分位低于 `50 ms`
- [ ] GC 无长暂停或持续恶化
- [ ] JFR/分析器已定位主要热点

## E. 客户端档案

- [ ] 干净源不含账号、日志、世界、截图或启动器缓存
- [ ] `hechao-profile.json` 的 versionId 和 Java 正确
- [ ] 两端共同 JAR 来自同一次构建且 SHA-256 一致
- [ ] 发布器生成签名档案
- [ ] 公钥独立验签通过
- [ ] `validate-release` 全对象闭合校验通过
- [ ] 私有 OSS 只上传缺失对象，远端不一致硬失败
- [ ] Test 安装、修复和启动通过
- [ ] Gray 观察通过
- [ ] Production 使用不可变清单
- [ ] 对象恢复集已刷新并验证

## F. 服务端部署

- [ ] 旧活动目录已设 Maintenance/Closed
- [ ] 未消费授权已过期，玩家数为 0
- [ ] `25568` 监听、PID、目录和核心已核对
- [ ] 世界、配置、模组/插件、启动文件和任务已备份
- [ ] 磁盘余量和恢复可读性通过
- [ ] 在隔离暂存目录校验服务端包
- [ ] 声明 `replace` 或 `overlay`，没有无差别融合旧插件
- [ ] 没有复制大厅、Survival 或旧活动服的完整 `plugins/mods/config`
- [ ] Authorizer 只在 Velocity，Lobby Guard/Tier Agent 只在内部大厅
- [ ] ServerControlAgent/StatusCollector/备份/告警通过主机目标注册
- [ ] 后端只有一个 forwarding 实现和一个兼容指标实现
- [ ] 每个获批 JAR 的来源、版本、许可证、SHA-256、所有者和回滚已记录
- [ ] 服务端停止后才替换 JAR
- [ ] 服控目标、状态采集、指标、备份和告警已接入
- [ ] 部署结束保持停止，除非本任务明确授权启动

## G. 生产启动与目录

- [ ] 通过后台结构化动作启动，没有裸 `java` 或结束全部 Java
- [ ] 冲突后端全部优雅停止后新目标才启动
- [ ] PID、端口、任务祖先和目录一致
- [ ] Minecraft、加载器、活动版本和 Java 正确
- [ ] 日志无依赖、注册、映射或世界错误
- [ ] 心跳、TPS/MSPT/GC、CPU、内存和磁盘新鲜
- [ ] 公网不能直连后端
- [ ] Velocity forwarding 和身份校验未降低
- [ ] 指标 JSON 与 StatusCollector 目标对应，TPS/MSPT/GC 数据新鲜
- [ ] 目录绑定正确 profileId 和 `velocityTarget=activity`
- [ ] 其他共享 activity 的目录记录不可进入
- [ ] 管理员 fresh grant 正确进服
- [ ] 错误档案、无权限和关闭状态被拒绝
